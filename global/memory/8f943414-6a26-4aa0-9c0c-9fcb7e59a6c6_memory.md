## Memory Block

**工作背景**
Kai（凯）是游戏设计师兼AI大模型产品经理，深耕AI+游戏应用领域，核心项目为和平精英AI队友系统。产品演进路径为绝地指挥1.0→2.0→3.0→智能战狗→AI托管→主题NPC，累计覆盖5160万用户，场景横跨PVP、回流社交、AI模式及主题模式。当前AI队友定位从陪玩转向独立人格，核心目标是建立长期养成关系，技术路线严格基于大语言模型实现，不接受规则系统。关注领域覆盖NPC对话、剧情生成、关卡设计、美术生产及测试自动化。

**个人背景**
表达风格简洁务实，反对概念包装，面向行业受众时注重高阶洞察与体验概念，而非技术细节。习惯先确认方向和大纲再执行，逐轮迭代微调，反对整体推翻。审阅交付物偏好Markdown文件格式，要求AI扮演审核角色提供批判性反馈并主动发现盲点，自身则给出聚焦的审查反馈，明确接受或拒绝具体建议。架构思考上偏好按内容类型和场景做结构化拆解，而非罗列功能。

**当前关注**
正在准备面向行业同行的分享PPT，内容聚焦框架和体验层面，按内容模块归纳，不展开技术细节。交付流程要求先输出HTML预览再转PPT。同时日常运营WorkBuddy流程（evaluate→extract→route→store）与"阿雾"早报自动化体系，后者基于30渠道情报源（AI大模型池15+游戏AI池10+校验池5），含记忆追踪与去重机制。

**近期动态**
- 开发AI NPC队友系统，专注模拟真人团队互动的多智能体群聊，群聊配置优先2+2和4+1，不优先1+3。
- 推进和平精英自研战斗策略大模型，以AI记忆+玩家画像为输入适配玩家风格，AI队友需主动找话题陪伴内向玩家同时避免社交压力。
- 搭建并持续运行30渠道AI+游戏情报早报自动化体系，配套记忆追踪与去重机制。

## 核心观点

1. **"规择感"是MDA理论的本土化实战框架** — 规(规则) · 择(选择) · 感(感受)，三者构成设计的逻辑闭环
2. **设计可以从任何一端切入** — 目标导向型(从"感"反推"规")，或规则验证型(从"规"预测"感")
3. **感受是分层的** — 即时层(打击感)→过程层(心流掌控感)→深层(宿命感/史诗感)，不同层级需要不同的设计手段
4. **玩家和设计师看同一个框架的方向相反** — 设计师：规→择→感（设计规则预测体验）；玩家：感→规（通过感受反推规则）

## 关键方法论/框架

### 框架：规择感三位一体模型

- **适用场景**: 任何游戏系统/玩法/机制的设计与评审

```
设计师视角（正向）                   玩家视角（逆向）
   规 ──→ 择 ──→ 感                  感 ──→ 规 ──→ 择
   │       │       │                  │       │       │
 设定规则  预测选择  校验感受          感官信号  推断规则  优化决策
```

**三要素定义**:
- **规（规则）**: 设计师设定的底层机制 — 动作帧数、伤害规则、叙事结构、经济公式
- **择（选择）**: 基于规则产生的决策 — 瞬时反应、资源管理、成长路线、社交策略
- **感（感受）**: 通过选择获得的体验 — 分三层:
  - **即时层**: 打击感、爽快感、挫败感
  - **过程层**: 心流感、掌控感、成长感
  - **深层**: 宿命感、史诗感、精神共鸣

### 两种设计路径

**路径A — 目标导向型（推荐）**:
1. 确定目标感受（如"史诗感"）
2. 反推需要什么样的选择来产生这种感受
3. 设计支撑这些选择的规则
4. 验证：实际体验是否达到目标感受？

**路径B — 规则验证型**:
1. 先设定规则
2. 预测玩家在此规则下会做出什么选择
3. 推演这些选择会产生什么感受
4. 校验：感受是否与设计意图一致？

| 游戏 | 规(规则) | 择(选择) | 感(感受) |
|------|---------|---------|---------|
| 《超级马里奥》 | 踩敌机制 | 跳跃/接触 | 即时：成就感/挫败感 |

| 《黑神话：悟空》 | 碎片叙事+属性克制 | 战术博弈+资源分配 | 孤独史诗感+反抗精神 |
| 《艾尔登法环》 | 开放地图+高惩罚 | 路线选择+风险管理 | 深层孤独感+征服感 |

### 玩家如何逆向使用框架

| 玩家路径 | 示例 |
|---------|------|
| 感→规 | 红光预警(感官信号) → 推断"Boss要放大招"(规则) |
| 规→择 | 发现导电机制(规则) → 雨天换装备(选择) |

## 设计检查清单

- [ ] **规则清晰度**: 规则是否可被玩家通过正常游玩推断出来？
- [ ] **选择有意义**: 每个选择是否对结果有实质影响？
- [ ] **感受分层**: 是否同时设计了即时层、过程层、深层感受？
- [ ] **正向验证**: 从规→择→感推演，感受是否与设计意图一致？
- [ ] **逆向验证**: 玩家能否从感(感官信号)→规(推断规则)？
- [ ] **感受信号**: 是否为每条重要规则设计了对应的感官信号(视觉/音效)？
- [ ] **选择权重**: 关键选择的代价/收益是否足以让玩家认真权衡？

## 金句/原文摘录

> "规是规则的规，代表游戏设计师设计出来各种规则；择是选择的择，融合了设计师和玩家双方的选择；感是感受的感——美感、代入感、挫败感、成就感以及史诗感。"

> "设计师和玩家看同一个框架的方向是相反的。"

## 个人思考

1. **"规择感"比MDA更好用** — MDA(Mechanics-Dynamics-Aesthetics)是学术语言，"规择感"是设计师语言，更直觉，更容易在评审中沟通
2. **感受分层是关键洞察** — 很多系统设计只关注即时层(爽不爽)，忽略了过程层(有没有掌控感)和深层(有没有精神共鸣)
3. **双向验证是质量保障** — 设计完毕后，既要正向验证(规→择→感)，也要逆向检查(玩家能否从感知信号推断规则)
4. **与认知双循环的关系** — "规则"构成问题系统，"选择"是操作循环，"感受"是认知成长的结果。两个框架互补
5. **跨能力应用** — 这个框架不限于系统设计，战斗设计(C5)、关卡设计(C6)、叙事设计(C7)都可以用

## 核心方法论

### 叙事系统设计目标
```
电子游戏 + 桌游即兴叙事 = 固定主线与自由选择共存
         ↓
    系统化支持
         ↓
   四大革命性系统
```

### 碎片化叙事设计原则
- **拒绝百科全书式说明**：模拟现实世界的信息获取方式
- **多角度呈现同一事件**：用系统重复强化而非简化认知
- **允许"困惑感"作为核心体验**：而非设计缺陷

## 关键技术点

### 1. 对话系统设计

#### 右侧布局的认知依据
```
传统游戏：对话框在左下方 → 视觉习惯
极乐迪斯科：对话框在右侧 → 仿操作系统弹窗设计
                         ↓
                   配合下滑式阅读框
                         ↓
                   模拟社交媒体体验
```

#### 技能检定系统
| 类型 | 设计目的 | 实现方式 |
|------|---------|---------|
| **主动检定** | 模拟骰子决策 | 玩家主动触发，概率判定 |
| **被动检定** | 真实心理模拟 | "思绪纷争→决策静默" |
| **人格辩论** | 多角度影响抉择 | 24种人格实时介入对话 |

### 2. 感官球系统
```
视觉/听觉/嗅觉 → 球状反馈 → 多维感知
       ↓
  即时环境感知
       +
  "后知后觉"的延时思考
```

### 3. 对话树系统
- **精密分支结构**：支撑100万字文本量
- **无意义趣味支线**：允许作家嵌入趣味内容（如金刚鹦鹉段落）
- **非线性叙事**：碎片化信息拼图式理解

### 4. 思维内阁系统
```
53种思维 → 触发条件（选择/阵营/技能）
         → 临时负面效果 + 永久立场加成
         → 动态平衡
```

**设计挑战**：曾因实现复杂度导致工作室濒临崩溃

## 实战案例

### 后社会主义叙事融入
- **创作背景**：ZA/UM团队经历苏联解体
- **场景设计**：瑞瓦肖城融合塔林工业废墟与超现实元素
- **叙事基调**："苏联寄出的最后一封信笺"

### 数字原生代阅读习惯培养
```
传统RPG → 大段文本 → 阅读负担
极乐迪斯科 → 视觉交互设计 → 培养阅读习惯
              ↓
    - 右侧对话框
    - 下滑式阅读
    - 技能弹窗
```

## 检查清单

### 叙事系统设计自检
- [ ] **主线与自由选择是否共存**：是否设计了非线性分支？
- [ ] **信息获取是否碎片化**：避免百科全书式说明？
- [ ] **技能检定是否丰富**：主动/被动/人格三种类型？
- [ ] **感官反馈是否多维**：视觉/听觉/嗅觉？
- [ ] **思维系统是否动态平衡**：负面效果与永久加成？

### 桌游改编电子游戏自检
- [ ] 是否保留了桌游的即兴叙事魅力？
- [ ] 系统设计是否支撑自由选择？
- [ ] 是否允许"困惑感"作为核心体验？
- [ ] 文本量是否可控（100万字级别）？

## 理论延伸

### 系统设计哲学
```
用系统重复强化 → 而非简化认知
       ↓
多角度呈现同一事件
       ↓
玩家自主拼图式理解
```

### 叙事与技术平衡
- **技术实现复杂度**：思维内阁系统曾导致工作室濒临崩溃
- **设计取舍原则**：用系统重复强化而非简化认知
- **允许困惑感**：作为核心叙事体验而非缺陷

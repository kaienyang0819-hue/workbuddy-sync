## 核心观点

**预选分路匹配的本质是流量分配问题**。通过"两阶段结构化建模"，将匹配系统抽象为"俄罗斯方块式"的供需调配过程，在小样本场景下实现MAE 2.69秒的高精度预测，同时具备强可解释性。

---

## 方法论

### 1. 两阶段结构化建模框架

**阶段一：复刻匹配优化流程（流量分配）**
```
首选保障（66.7%强制）→ 次选调配（削峰填谷）→ 补位填充（缺口补齐）
```

**核心机制**：
- **首选保障**：通过马尔可夫过程推导，强制分配66.7%玩家至首选分路
- **次选调配**：最小化分路占比极差，SLSQP算法优化弹性系数
- **补位填充**：补位玩家按分路缺口比例分配

**阶段二：供需缺口预测时长**
```
匹配时长 = f(相对供需缺口, 理想供需缺口)
```

### 2. 双缺口特征设计

| 特征 | 定义 | 计算方式 |
|------|------|---------|
| **相对供需缺口** | 分路间拥堵差异 | 分路间供需占比差异 |
| **理想供需缺口** | 偏离20%均衡值程度 | \|实际占比 - 20%\| |

**预测模型**（双缺口线性模型）：
```
Time = 289.9 × RelativeGap + 120.5 × IdealGap + 7.1
```

**精度验证**：
- MAE 2.69秒（平均绝对误差）
- 优于单缺口模型、二次模型
- 小样本场景（90天数据）仍保持高精度

## 案例研究

### 案例1：辅助位匹配时长激增诊断

**现象**：冷门辅助位突然拥堵，匹配时长异常增长

**诊断过程**：
1. 检查相对供需缺口 → 发现中路拥堵
2. 分析补位资源流向 → 中路挤占辅助补位资源
3. 根因：中路玩家增加 → 补位玩家优先填补中路 → 辅助位失去补位红利

**解决思路**：
- 调整补位AI投放策略
- 动态平衡分路优先级权重

### 案例2：预选分路功能上线时长预测

**挑战**：
- 新系统数据样本稀缺（仅90天）
- 多重耦合机制（首选保障+次选分流+补位填充）
- 预测匹配时长增长幅度

**解决方案**：
1. 结构化建模复刻匹配流程
2. 双缺口特征精准量化供需不平衡
3. 模拟不同参数下的最坏情况

**价值**：
- 提前预判匹配时长增长
- 指导补位AI投放量优化
- 支持服务器策略调整前预验证

## 延伸思考

### 结构化建模 vs 黑箱模型

| 对比维度 | 结构化建模 | 黑箱模型 |
|---------|-----------|---------|
| **数据需求** | 小样本即可（90天） | 需要大量数据 |
| **可解释性** | 强（可追溯根因） | 弱（黑箱） |
| **预测精度** | 高（MAE 2.69秒） | 取决于数据量 |
| **迭代速度** | 快（参数调整） | 慢（重新训练） |
| **业务价值** | 诊断+预测+优化 | 仅预测 |

**适用场景**：
- **结构化建模**：业务规则明确、数据稀缺、需强可解释性
- **黑箱模型**：数据充足、规则复杂难以建模、仅需预测

### 匹配系统的本质

**匹配不是简单的"技能平衡"问题，而是复杂的流量分配问题**：

1. **多重约束耦合**：等待时间、技能平衡、分路偏好、补位机制
2. **动态供需博弈**：玩家行为实时变化、分路热度周期性波动
3. **体验边界探索**：不同参数下的最坏情况模拟

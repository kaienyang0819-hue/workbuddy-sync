## 核心观点

1. **期望值是"概率加权平均"** — 代表随机事件重复多次的平均结果，是数值策划的核心度量工具
2. **四大应用场景**: 伤害期望(战斗平衡) · 产出期望(资源节奏) · 消耗期望(养成成本) · 抽卡期望(获取成本)
3. **期望值有三大局限**: 不反映个体差异、不量化主观感受、不覆盖无形价值
4. **期望值+保底=完整方案** — 单靠期望值不够，必须结合保底机制控制极端情况

## 关键方法论/框架

### 四大场景计算

| 场景 | 公式核心 | 案例 | 设计用途 |
|------|---------|------|---------|
| **伤害期望** | 基础伤害×(1-闪避率)×(1+暴击率×暴击倍率) | 法师火球228点/次→击杀需N次 | 战斗平衡 |
| **产出期望** | Σ(资源价值×掉落概率) | 杀野猪=19元宝/次→日收入预测 | 资源节奏 |
| **消耗期望** | 单次消耗÷成功率 | 强化+10需1000颗石(50颗/天=20天) | 养成周期 |
| **抽卡期望** | 1÷目标概率 | SSR 1%→期望100抽 | 获取成本 |

### 期望值三大局限与解法

| 局限 | 问题 | 解决方案 |
|------|------|---------|
| 不反映个体差异 | "欧皇"1发出金vs"非酋"200发 | 方差控制 + **保底机制** |
| 不量化主观感受 | 免费vs付费玩家情绪差异 | 玩家分层设计 + 用户反馈 |
| 不覆盖无形价值 | 闪避反击的爽感>数值差异 | 优先保证玩法乐趣 |

### 核心公式：期望值+保底

```
实际获取成本 = min(期望成本, 保底成本)
设计目标: 保底成本 ≈ 1.5-2倍期望成本（既控制极端又保留随机感）
```

## 设计检查清单

- [ ] **伤害验算**: 是否用期望值验算了击杀时间/战斗时长？
- [ ] **产出验算**: 日/周资源产出期望是否匹配养成节奏？
- [ ] **消耗验算**: 关键养成节点的期望消耗是否在合理范围？
- [ ] **抽卡保底**: 概率类系统是否有保底机制？保底倍率是否合理？
- [ ] **极端验证**: 是否考虑了最差运气的玩家体验？
- [ ] **亲身体验**: 设计的数值是否亲自玩过验证？

## 个人思考

1. **期望值是C2数值设计的"计算器"** — 4×4框架告诉你"做什么"，期望值告诉你"算多少"
2. **"保底机制"是数值设计对玩家心理的让步** — 数学上合理不代表体验合理，200抽不出SSR在概率上"正常"但在体验上"不可接受"
3. **与C4心理的关联** — 损失厌恶让玩家对"亏"的感受远大于"赚"，保底机制本质是在管理损失厌恶

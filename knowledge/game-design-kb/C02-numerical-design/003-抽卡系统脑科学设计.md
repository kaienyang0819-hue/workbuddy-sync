## 核心观点

1. **抽卡的爽感来自"等待和反转"，而非直接获得奖励** — 多巴胺峰值出现在悬念阶段
2. **核心机制是奖励预测误差(RPE)** — 实际奖励>预期时多巴胺爆发（如金卡转橙卡）
3. **抽卡过程是"三幕剧"** — 线索出现→悬念积累→奖励反转，每幕对应不同的脑区激活
4. **动效是放大器，不是替代品** — 核心吸引力（角色/经济）不够，动效再好也没用

## 关键方法论/框架

### 框架：抽卡多巴胺三幕剧

```
多巴胺水平
    ↑      
    │          ╱╲  ← 第三幕：奖励反转（金转橙）
    │         ╱  ╲   多巴胺脉冲 +150%
    │    ╱───╱    ╲
    │   ╱           ╲  ← 第二幕：悬念积累（手动交互）
    │  ╱              ╲   维持高水平1.5-4.5秒
    │ ╱
    │╱ ← 第一幕：线索出现（寻访包落下）
    │    纹状体预激活
    └───────────────────→ 时间
```

| 幕 | 脑区 | 设计手段 | 时长 |
|---|------|---------|------|
| **第一幕：线索** | 纹状体 | 寻访包落下动画 | 0.5-1s |
| **第二幕：悬念** | 脑岛+纹状体 | 手动拉链/拖拽交互 | 1.5-3s |
| **第三幕：反转** | 多巴胺脉冲 | 金→橙的视觉反转 | 瞬间 |

### 四条可执行优化策略

| 策略 | 具体操作 | 原理 |
|------|---------|------|
| **视觉欺骗** | 前摇降饱和度20-30%→出卡瞬间拉满+过曝 | 制造"视觉能量拐点" |
| **时间微调** | 悬念窗口1.5-3秒（短了加蓄力，长了压动效） | 多巴胺最佳维持区间 |
| **交互阻力** | 插入划动/拖拽轻交互 | 制造"控制错觉"（玩家归因于自身操作） |
| **震动反馈** | R卡单次轻震/SR两次鼓点/SSR长+短震 | 触觉先于视觉传递结果 |

## 设计检查清单

- [ ] **三幕完整**: 线索→悬念→反转是否都有设计？
- [ ] **悬念时长**: 核心悬念是否在1.5-3秒区间？
- [ ] **反转设计**: 是否有"先压低预期再超越"的反转机制？
- [ ] **手动交互**: 玩家是否有"操控感"而非纯被动等待？
- [ ] **震动分级**: 不同稀有度的触觉反馈是否有区分？
- [ ] **跳过权**: 重复抽卡时是否允许跳过动画？

## 个人思考

1. **"控制错觉"是极其精妙的设计** — 让玩家觉得"是我操作得好才出的SSR"，增强满足感
2. **与C4行为设计的深度关联** — 可变比率奖励+RPE+沉没成本，抽卡系统是行为设计的集大成者
3. **C2和C8的交叉点** — 数值（概率/保底）决定了"出什么"，UI/交互决定了"感觉如何出"

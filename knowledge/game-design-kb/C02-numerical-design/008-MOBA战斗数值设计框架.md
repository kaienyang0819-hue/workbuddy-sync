## 一、战斗体验三要素

### 1. TTK (击杀时间)
- **MOBA标准**: 5-8秒(射手互点)
- **设计原则**: 需与技能输出循环节奏匹配
- **问题诊断**:
  - TTK过长 → 垃圾时间,战斗冗长
  - TTK过短 → 意犹未尽,缺乏策略

### 2. RTK (击杀回合数)
- **作用**: 控制战斗频率与先手优势
- **差异化设计**:
  - 刺客: 低RTK(高爆发,2-3次攻击)
  - 坦克: 高RTK(拉锯战,10+次攻击)

### 3. 数值量级选择

| 方案 | 血量 | 伤害 | 特点 | 案例 |
|------|------|------|------|------|
| 方案A | 3位数 | 2位数 | 竞技性强 | 早期MOBA |
| 方案B | 5位数 | 4位数 | 视觉冲击 | RPG向MOBA |
| **方案C** | **4位数** | **3位数** | **平衡方案** | **王者荣耀/LOL** |

**王者荣耀案例**: 
- 1级射手: 3000血量, 180攻击
- 15级射手: 6000血量, 600攻击
- 单局成长横跨量级,适配方案C

## 二、伤害公式设计

### 1. 减法公式 (破防机制)
```
实际伤害 = 攻击力 - 防御力
```
- **适用场景**: MMORPG付费驱动
- **问题**: 无效堆防风险(防御>攻击)

### 2. 除法公式 (减伤率)
```
减伤率 = 防御力 / (防御力 + K)
实际伤害 = 攻击力 × (1 - 减伤率)
```
- **适用场景**: MOBA公平竞技
- **优势**: TTK稳定,防御软上限

### 3. 英雄联盟减伤公式
```
减伤率 = 护甲 / (护甲 + 100)
```
- **100护甲**: 减伤50%
- **200护甲**: 减伤67%(收益递减)
- **300护甲**: 减伤75%(软上限明显)

## 三、数值多样性拓展

### 1. 伤害拆分维度
- **攻速差异**: 慢速高伤 vs 快速低伤
- **暴击机制**: 稳定输出 vs 爆发风险
- **穿透属性**: 百分比穿透 vs 固定穿透

**设计范例**:
- 后羿(射手): 高攻速+暴击流
- 孙尚香(射手): 低攻速+爆发流

### 2. 生存拆分维度
- **生命回复**: 持续作战能力
- **闪避率**: 概率生存机制
- **吸血**: 以攻代守策略

**职业原型**:
- 坦克: 高生命+高防御+回复
- 刺客: 低生命+闪避+吸血
- 法师: 中生命+护盾+魔免

## 四、装备系统设计

### 1. 装备本质
- **定义**: 基础属性的**再分配系统**
- **价值锚点**: 
  - 2:1基础装备比(2件基础装备合成1件高级装备)
  - 4件装备为标准配置(LOL 6件 → 王者荣耀简化)

### 2. 属性等价转换模型

**价值转换表** (以生命值为锚点):

| 属性 | 价值等价 | 备注 |
|------|---------|------|
| 300生命 | 1价值单位 | **锚点** |
| 75防御 | 300生命 | 减伤收益等价 |
| 20%闪避率 | 300生命 | 期望生存等价 |
| 25%攻速 | 300生命 | DPS提升等价 |
| 15%暴击率 | 300生命 | 期望伤害等价 |

**装备混合投放原则**:
- 总价值守恒(以生命值为锚点)
- 组合投放需保证总值一致
- 例: 300生命+75防御 = 600价值单位

### 3. 特性设计原理

#### 主动技能价值量化
**三元耦合模型**:
```
收益期望 = 效果强度 × 持续时间 / 冷却时间
```

**案例**: 
- 60秒CD减伤50% ≈ 常驻100防御
- 120秒CD无敌3秒 ≈ 常驻150防御

**设计原则**:
- 高CD大招 → 效果炸裂(改变战局)
- 低CD小技能 → 效果温和(战术补充)

#### 被动技能价值量化
**触发条件约束**:
```
收益覆盖率 = 触发频率 / 最大频率
```

**案例**:
- 每4次普攻触发额外伤害 ≈ 常驻40攻击力
- 暴击触发移速加成 ≈ 常驻10%移速(需暴击率支撑)

## 五、实战案例

### 案例1: DOTA2装备价值体系
- **圣剑**: +300攻击(极端投入,死亡掉落)
- **黑皇杖**: 魔免10秒(主动技能,高价值)
- **跳刀**: 瞬移1200距离(战术价值>属性价值)

### 案例2: 英雄联盟装备分类
- **核心装**: 提供关键属性(无尽之刃=暴击伤害)
- **功能装**: 提供战术价值(中亚沙漏=无敌2.5秒)
- **防御装**: 提供生存能力(兰顿之兆=减暴击伤害)

### 案例3: 王者荣耀装备简化
- **移除主动装备**: 降低操作门槛
- **简化合成路径**: 2件基础装备合成
- **强化被动特效**: 装备价值体现在属性+被动

## 六、方法论总结

### MOBA数值设计三步法

**Step 1: 确定核心体验指标**
- TTK标准: 5-8秒(射手互点)
- RTK范围: 5-15次攻击
- 数值量级: 4位数血量+3位数伤害

**Step 2: 构建伤害公式体系**
- 选择除法公式(减伤率)
- 设定防御常数K(如100)
- 验证TTK稳定性

**Step 3: 设计装备价值体系**
- 建立属性等价转换表
- 设定装备合成规则(2:1)
- 平衡主动/被动技能价值

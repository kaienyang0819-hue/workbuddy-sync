## 一、如何衡量游戏产出

### 1. 借鉴现实GDP指标
```
游戏总产出 = 玩家消费总值 + 储蓄总值 + 转移支付
游戏生产净值 = 总产出 - 装备折损 - 装备掉落
```

**转移支付计算**:
- 官方福利(装备套装) - 交易税 = 价值增量
- 避免重复计算(物品价值只计首次增量)

### 2. 产出倾向判定

| 类型 | 生产净值π | 特点 | 案例 |
|------|----------|------|------|
| 膨胀型 | π > 0 | 产出增加,资源积压 | 萤火突击 |
| 紧缩型 | π < 0 | 产出减少,资产缩水 | 暗区突围 |

## 二、产出倾向对DAU的影响

### 1. 剩余价值理论应用

**必要劳动时间**: 满足基本需求(如买把枪)
**剩余劳动时间**: 额外收益(如攒钱买高级装备)

**DAU影响分析**:
- 紧缩型: 必要劳动时间↑ → 玩家负反馈增强 → 需丰富内容维持活跃度
- 膨胀型: 剩余劳动时间↓ → 玩家过早满足 → 易退游

### 2. 适用场景

| 品类 | 推荐类型 | 原因 |
|------|---------|------|
| 核心向小DAU | 紧缩型 | 高内容更新率,强紧张感 |
| 休闲向大DAU | 膨胀型 | 弱依赖资源,轻松体验 |

---

## 三、不同产出倾向的影响维度

### 1. 核心体验
- **膨胀型**: 弱依赖资源,适合休闲游戏(超自然行动组)
- **紧缩型**: 强依赖资源,增强紧张感(硬核生存)

### 2. 资源循环
- **膨胀型**: 易资源积压 → 需设计消耗机制
- **紧缩型**: 需防低损耗无聊 → 设计低保或随机化

### 3. 数值成长与玩家分层
- **膨胀型**: 易新老玩家失衡 → 赛季衰减
- **紧缩型**: 需防经济崩盘 → 随机化或贬值

### 4. 商业化策略
- **膨胀型**: 外观付费为主
- **紧缩型**: 卖金需避免破坏平衡

## 四、物价水平控制

### 1. 物价公式
```
平均交易价 = 有效交易次数 × 可交易货币总量 / 物资流通量
```

### 2. 膨胀产出控制方法

| 方法 | 优点 | 缺点 |
|------|------|------|
| 官方低价供货 | 平抑物价 | 反向刺激需求 |
| 限制交易次数 | 减少流通 | 降低活跃度 |
| 征税 | 回收货币 | 增加交易成本 |
| **银行系统** | **抑制流通** | **鼓励存款** |

### 3. 银行系统设计
```
利率 = 通胀率 + 净产出增长率
```
- 抑制货币流通,鼓励玩家存款
- 减少市场交易,控制通胀

### 搜打撤经济系统设计五步法

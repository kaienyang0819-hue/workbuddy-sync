## 核心方法论

### 商业化五问链路
```
卖什么 → 怎么卖 → 卖给谁 → 什么时候卖 → 卖多少钱
  ↓         ↓         ↓           ↓            ↓
付费结构  销售手段   用户分层   活动运营      定价策略
```

### 付费类型两大核心
| 类型 | 收入占比 | 设计要点 | 典型形式 |
|------|---------|---------|---------|
| **属性付费** | 60%+ | 战斗力分段式获取 | 角色升级+装备+宠物组合 |
| **外观付费** | 依赖炫耀场景 | 价值模型构建（6-288元阶梯） | 皮肤+特效+称号 |

### 用户分层三级价格歧视
```
一级歧视：新手首充6元礼包（一次性优惠）
二级歧视：累计充值梯度返利（阶梯奖励）
三级歧视：大R专属客服通道（定制服务）
```

## 关键技术点

### 1. 销售手段分层矩阵
| 道具类型 | 目标群体 | 典型形式 | 设计要点 |
|----------|----------|----------|----------|
| 绝品道具 | 超R（0.1%） | 0.1%概率转盘 | 制造稀缺性+保底机制 |
| 高级道具 | 大R（1-5%） | 限时直购礼包 | 控制产出节奏 |
| 常规道具 | 全体玩家 | 周卡/月卡 | 稳定价格体系 |

### 2. 活动设计七类矩阵
```
拉新类：邀请返利 → 新玩家增长
留存类：七日登录 → 次日/七日留存
活跃类：每日任务 → DAU/在线时长
消耗类：转盘抽奖 → 道具库存清理
付费类：BattlePass → 付费渗透率
召回类：老玩家礼包 → 流失玩家召回
复合类：囤货+消耗 → 系统联动
```

### 3. 关键数据指标监控
- **ARPU值**：每用户平均收入
- **付费渗透率**：付费用户占比
- **活动参与率**：参与人数/活跃人数
- **道具复购率**：二次购买比例

## 实战案例

### SLG类商业化设计
- **付费结构**：大R主导型（TOP 5%玩家贡献80%收入）
- **核心付费点**：加速+资源+战争护盾
- **平衡机制**：非R玩家提供战争生态，通过"溢价试探"挖掘大R潜力

### 休闲类商业化设计
- **付费结构**：低额高频型（小额+高频次）
- **核心付费点**：复活+提示+装扮
- **广告变现**：激励视频+插屏广告组合

## 检查清单

### 商业化设计自检五问
- [ ] **卖什么**：是否建立了核心付费结构（属性+外观）？
- [ ] **怎么卖**：销售手段是否覆盖超R/大R/中R/小R分层？
- [ ] **卖给谁**：RFM模型用户画像是否清晰？
- [ ] **什么时候卖**：活动矩阵是否覆盖拉新/留存/活跃/付费？
- [ ] **卖多少钱**：定价策略是否应用三级价格歧视？

### 付费/非付费平衡检查
- [ ] 非R玩家基础体验是否保障？
- [ ] 付费道具是否破坏公平性？
- [ ] 是否设计"溢价试探"机制？

## 理论延伸

### 商业化与马斯洛需求映射
```
生理需求 → 基础游戏体验（免费）
安全需求 → 保护/安全类道具
社交需求 → 外观/炫耀类道具
尊重需求 → 排名/特权/专属标识
自我实现 → 极致追求/收藏成就
```

### 定价心理学原理
- **锚点效应**：通过高价商品建立心理锚点，使中档商品显得"划算"
- **损失厌恶**：限时/限量制造紧迫感（FOMO）
- **沉没成本**：累计充值梯度奖励强化持续付费

# 损失厌恶与FOMO：游戏心理学武器库

> **核心观点**：损失厌恶（Loss Aversion）和FOMO（Fear of Missing Out）是游戏设计中最强大的心理杠杆——人们对失去的痛苦感约为获得快乐的2倍。合理运用可提升参与度，过度使用则引发玩家反感。

## 方法论

### 损失厌恶在游戏中的应用
| 设计模式 | 心理机制 | 使用建议 |
|---------|---------|---------|
| **限时活动** | "错过就没了" | 频率适中，避免疲劳 |
| **每日登录** | "断签损失" | 允许补签减缓焦虑 |
| **排名衰减** | "不玩就掉段" | 设置安全区保护 |
| **即将过期** | "快用否则浪费" | 给充足使用时间 |
| **Battle Pass** | "已投入不能浪费" | 合理进度设计 |

### FOMO的双面性
- **正面**：提升活动参与率、促进社交传播、创造话题性
- **负面**：产生焦虑、引发厌倦、逼退休闲玩家
- **平衡点**：FOMO应该让玩家"想玩"而非"被迫玩"

### 健康设计原则
1. **可预期性**：提前告知活动时间，让玩家安排
2. **可追溯性**：过期内容有复刻/替代获取途径
3. **非必要性**：限时内容不影响核心竞争力
4. **渐进释放**：不要同时放出太多FOMO事件

## 检查清单
- [ ] 损失厌恶设计是否适度（不引发焦虑）？
- [ ] 限时内容是否有后续获取途径？
- [ ] FOMO是否影响了核心竞争力平衡？
- [ ] 是否让玩家"想玩"而非"被迫玩"？

# 游戏广告：平衡收入与用户体验

> **核心观点**：游戏内广告的核心矛盾是"收入最大化vs体验不打扰"。通过个性化推荐、原生广告、奖励广告等策略，可以在不破坏玩家体验的前提下实现商业化。

## 方法论

### 游戏广告体验光谱
```
强打扰 ←——————→ 弱打扰
插屏广告 > 横幅广告 > 原生广告 > 奖励广告
收入高    收入中     收入低     体验最好
```

### 玩家对广告的心理反应
- **反感触发点**：打断心流/强制观看/与游戏风格不符
- **接受条件**：可选/有奖励/内容相关/不影响进度
- **最佳实践**：奖励广告——玩家主动选择观看换取奖励

### 平衡策略
1. **场景适配**：在自然休息点（关卡间/死亡后）展示
2. **频率控制**：单位时间内广告次数上限
3. **个性化**：根据玩家偏好推荐相关广告
4. **AB测试**：持续测试不同广告策略对留存的影响

## 检查清单
- [ ] 广告是否在自然休息点展示？
- [ ] 玩家是否有选择权（跳过/自愿观看）？
- [ ] 广告频率是否有上限控制？
- [ ] 是否监控广告对留存的影响？

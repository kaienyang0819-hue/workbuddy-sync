# 玩家心理学检查清单总纲

> **核心观点**：玩家心理学是游戏设计的底层操作系统——所有系统/数值/叙事/商业化设计最终都要回到"玩家感受到什么"。本卡片汇总C4全部知识，形成从动机→体验→情绪→社交→商业化的完整心理学检查体系。

## 五维心理学检查体系

### 1. 动机与目标
- [ ] 核心玩家的主要动机类型是否明确？（Bartle/Quantic Foundry）
- [ ] 短期/中期/长期目标是否层层嵌套？
- [ ] 不同动机玩家之间是否有正向互动？
- [ ] 是否考虑了玩家动机的阶段性变化？

### 2. 心流与注意力
- [ ] 挑战-技能是否动态平衡？
- [ ] 反馈是否足够即时和清晰？
- [ ] 美术/叙事/玩法的注意力是否有节奏配合？
- [ ] 是否避免了强制打断心流的设计？

### 3. 情绪与沉浸
- [ ] 沉浸感是否覆盖五层（物理/认知/情感/社交/叙事）？
- [ ] 情感化设计是否覆盖三层次（本能/行为/反思）？
- [ ] 失败体验是否被正向设计（学习/叙事/挑战）？
- [ ] 是否有情绪响应机制（DDA/动态难度）？

### 4. 社交与社区
- [ ] 社交系统是否有弱/中/强多层次？
- [ ] 社会比较是否适度（不引发挫败）？
- [ ] 社区管理模式是否与游戏类型匹配？
- [ ] 舆情监控是否能快速响应？

### 5. 心理学与商业化
- [ ] 损失厌恶/FOMO是否适度使用？
- [ ] 随机奖励是否有保底和透明概率？
- [ ] 广告是否在自然休息点且可选？
- [ ] 玩家感受是"愉悦"还是"被迫"？

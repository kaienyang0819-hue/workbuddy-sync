## 核心观点

1. **战斗系统由三层构成**：玩法机制（脑）→ 战斗表现（眼&耳）→ 操作手感（手），战斗表现是玩家接收的第一信号
2. **优秀战斗表现的三大标准**：清晰感、节奏感、质感——所有设计决策都应围绕这三个维度检验
3. **战斗表现分8个设计维度**：动作、特效、音效、受击、镜头、演绎、天气、UI，每个维度都有独立的设计方法论
4. **"量变产生质变"原则**：受击动作越丰富越真实；细节堆叠是区分A级和S级战斗体验的关键
5. **克制比堆料更重要**：震屏、顿帧、特效等表现手段必须克制使用，过度则适得其反

## 关键方法论/框架

### 框架一：战斗表现八维度模型

- **适用场景**: 任何需要设计或评审战斗表现的项目
- **八个维度**:
  1. **动作** — 力量感(重心/动力链/速度) + 性格体现 + 代入感
  2. **特效** — 色彩形态 + 时间节奏(蓄力→爆发→消退) + 氛围构图
  3. **音效** — 力度维持 + 状态反馈 + 材质区分 + 声音层级
  4. **受击** — 受击动作 + 受击特效 + 顿帧 + 震屏 + 环境交互
  5. **镜头** — 机位选择(①号/②号/③号) + 运镜(锁定/非锁定)
  6. **演绎** — BOSS战预编排动画(有来有回/节奏张弛/环境互动/电影运镜)
  7. **天气** — 战斗氛围营造(不是背景板，是沉默主角)
  8. **UI(HUD)** — 游戏性格的延伸(侵略性vs克制)

### 框架二：动作力量感三要素

- **适用场景**: 角色攻击动作设计
- **三要素**:
  1. **重心与平衡**: 肚脐→地面垂直投影点在两脚之间=稳定；特殊动作允许短时偏移
  2. **动力链**: 力量传导 脚→腿→腰→肩→拳，手是末端，腿是发源地
  3. **速度节奏**: 重=慢(突出惯性)，轻=快(突出连贯)；用时间轴设计前后摇时长比
- **公式**: 重型武器 = 慢(准备)-快(攻击)-慢(收招)；轻型武器 = 快-快-快

### 框架三：特效节奏三段式

- **适用场景**: 技能/攻击特效设计
- **三段结构**:
  1. **蓄力(0.5-2s)**: 能量由外向内聚集，速度渐快，体积渐小
  2. **爆发(0.1-0.3s)**: 峰值表现，速度快
  3. **消退(1-3s)**: 余波扩散，速度递减——这步非常重要，增加高级感
- **注意事项**: 消退阶段容易被忽略，但它是区分"廉价感"和"高级感"的关键

### 框架四：顿帧设计准则

- **适用场景**: 打击感调优
- **时机选择**:
  - 写实/格斗 → 击中瞬间（精准）
  - 夸张战斗 → 特效最大最亮最展开的瞬间
- **时长**: 通常0.05-0.08秒，极大威力可超0.1秒
- **最高境界**: "顿了但不卡"
- **进阶策略**: 敌人动作+主角动作减帧，但受击特效保持原速（保流动感）——出自《绝区零》

### 框架五：镜头机位选择矩阵

| 机位 | 典型品类 | 特点 | 代表作 |
|------|----------|------|--------|
| ①号(居中对称) | 2D格斗 | 公平直观 | 《街霸》 |
| ②号(角色后方) | ARPG | 配合锁定，精准操作 | 《黑魂》 |
| ③号(略偏移) | ACT/3D格斗 | 展现细节和对峙张力 | 《战神》 |

## 设计检查清单

- [ ] **动作力量感**: 重心是否在合理范围？动力链是否从脚发力？
- [ ] **动作个性**: 角色是否有标志性动作？动作节奏是否匹配性格？
- [ ] **特效色彩**: 颜色是否统一属性+效果+性格？边缘是否清晰？
- [ ] **特效节奏**: 是否有蓄力→爆发→消退的完整三段？消退是否足够？
- [ ] **特效过冲**: 尺寸是否适当超过武器长度（夸张风格）？
- [ ] **音效层级**: 格挡>击中>攻击>喊话的优先级是否正确？
- [ ] **音效材质**: 金属/木/皮材质是否有区分？
- [ ] **受击多样性**: 受击动作是否足够丰富？是否区分部位？
- [ ] **受击特效位置**: 是挂骨骼/碰撞点/全身闪白？是否适合项目风格？
- [ ] **顿帧时机**: 是在击中瞬间还是特效展开瞬间？时长是否在0.05-0.08s？
- [ ] **震屏克制**: 幅度是否让玩家"感知不到但客观存在"？频率是否适度？
- [ ] **环境交互**: 攻击是否在场景留下痕迹？
- [ ] **镜头机位**: 是否选择了适合品类的机位？
- [ ] **锁定策略**: 是否处理了BOSS高速移动时的防晕机制？
- [ ] **天气协同**: 天气是否参与了战斗情绪的营造？
- [ ] **UI风格**: HUD风格是否与游戏气质一致？

## 个人思考

1. **八维度模型是很好的战斗评审框架** — 可以直接用于项目的战斗设计Review，逐维度检查是否达标
2. **特效三段式(蓄力→爆发→消退)的"消退"环节** — 很多项目只做前两段就觉得够了，消退是区分品质的关键
3. **"克制"的设计哲学** — 震屏、顿帧、闪白等手段不是越多越好，滥用会导致信息噪声，降低核心打击的区分度
4. **镜头机位选择** — 作为系统策划容易忽略的维度，但它直接影响玩家的空间感知和操作精准度
5. **与AI的结合点** — 受击动作的多样性需求巨大(按部位/按方向/按力度)，未来可能是AI动画生成的重要应用场景

# 浪人崛起石火动摇机制

> **核心观点**：通过"石火-动摇"机制解决格挡反击玩法与动作交互体验的矛盾。动摇状态破除敌人霸体+强化玩家精伤，实现攻防转换的核心枢纽。

## 🎯 核心方法论

### 核心机制三角

```
        石火（Counterspark）
             ↓
    ┌────────┴────────┐
    ↓                  ↓
动摇（Panic）      闪刃（Blade Flash）
    ↓                  ↓
破除霸体          精力管理
强化玩家输出      重置连段
```

### 三大核心机制

| 机制 | 功能 | 设计目的 |
|------|------|---------|
| **石火** | 核心格挡反击动作，兼具防御与进攻判定 | 高风险高收益 |
| **动摇** | 敌人失衡状态，破除霸体+进攻加成 | 攻防转换枢纽 |
| **闪刃** | 精力管理核心，回复精力+重置连段+取消后摇 | 类似《仁王》残心 |

## 💡 关键洞察

### 1. 石火机制的突破

#### 传统格挡反击的矛盾
```
《卧龙》化解问题：
化解收益 >> 进攻
→ 决策固化（玩家不进攻）
→ 战斗节奏僵化
```

#### 浪人的解决方案
```
石火设计：
成功判定：严格（高风险）
收益：动摇时间 + 精力回复
惩罚：失败后摇（高惩罚）

同时赋予：
角色丰富的武技
高取消优先级动作（闪刃/紫电/烈风）
→ 鼓励进攻 + 保留格挡反击价值
```

### 2. 动摇机制的革新性

#### 动摇状态的双重效果
1. **剥夺敌人霸体** - 玩家可打断敌人动作
2. **强化玩家精伤** - 进攻加成倍率

#### 核心价值
- **格挡反击与动作交互共存**
- 为高速攻防转换提供设计基础

### 3. 战斗循环裂痕与修复

#### 流派克制系统的问题
```
天/人/地/忍四流派克制
克制关系直接影响石火收益
被克制流派：石火收益锐减
→ 与玩家训练的操作习惯冲突
```

#### 后期被动修复
- 装备词条（如"紫电/烈风取消流派不利"）
- 缓解但未根治流派克制的设计矛盾

### 4. 3C系统与敌人AI

#### 控制优化
- 组合键（R1+功能键）降低操作门槛
- 兼顾动作深度与轻度玩家体验

#### 对决式相机设计
- 倾斜视角模拟剑戟片对峙感
- 提升代入感与动作可读性
- **不足**：版边遮挡处理不足

#### 敌人AI动态变招
- 多层级随机变招（非固定派生）
- 提升重复游玩价值
- **问题**：高难度下信息过载+惩罚失衡

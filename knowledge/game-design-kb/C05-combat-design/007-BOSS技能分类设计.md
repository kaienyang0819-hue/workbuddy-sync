# BOSS技能分类设计

> **核心观点**：BOSS技能分为白给招、偷袭招、难招、大招四类，每类承担不同功能（缓和节奏、调剂新鲜感、制造压力、高峰体验），通过帧数控制与行为检测优化战斗节奏。

## 🎯 核心方法论

### 技能分类框架

```
BOSS技能矩阵：
┌─────────┬──────────┬──────────┐
│  白给招  │  偷袭招  │  难招    │
│ 低压力期 │ 调剂新鲜感 │ 制造压力  │
├─────────┴──────────┴──────────┤
│           大招                 │
│     高峰体验/阶段转换          │
└───────────────────────────────┘
```

## 💡 关键洞察

### 1. 四类技能详解

#### 白给招
**特点**：
- 段数多，间隔固定
- 攻击帧清晰，处理难度低

**功能**：
- 缓和节奏
- 保底交互
- 资源循环（如格挡恢复资源）

**案例**：沙克图卡五连击
- 提供低压力期
- 为下一波高强度铺垫

#### 偷袭招
**特点**：
- 前摇迷惑性强（"假后摇"设计）
- 段数少（1-2段）
- 帧数控制（约30帧）

**功能**：
- 打破玩家预期
- 调剂新鲜感

**案例**：沙克图卡拍爪二连
- 行为检测：根据玩家状态调整后续动作
- 制造"惊喜"而非"惊吓"

#### 难招
**特点**：
- 快慢刀、不可防御、强追踪
- 高处理难度

**功能**：
- 制造压力
- 高挑战

**设计要点**：
- **难招处理后必须有补偿**
- 如长时间僵直或输出机会
- 通过性能差异（出招次数限制）维持心流

**案例**：冲刺攻击
- 高威胁
- 但成功躲避后给玩家大额输出窗口

#### 大招
**特点**：
- 场面感强
- 机制载体

**两类大招**：

| 类型 | 特点 | 节奏作用 |
|------|------|---------|
| 单独考验型 | 独立循环 | 提供高峰体验，结束回归正常 |
| 阶段转换型 | 开启新阶段 | 提升后续难度，可能以另一大招结束 |

**设计要点**：
- 补偿输出时间损失（反击机会）
- 阶段循环设计

---

### 2. 关键设计技巧

#### 帧数控制
```
白给招：间隔固定，清晰可读
偷袭招：约30帧（第二段）
难招：快慢刀节奏变化
大招：演出时间+玩家反应窗口
```

#### 行为检测
```
基于玩家状态动态调整：
- 玩家距离 → 选择近战/远程技能
- 玩家血量 → 控制压力强度
- 玩家位置 → 选择AOE/单体技能
```

#### 设计流程
```
整体战斗体验 → BOSS AI行为 → 所需技能类型
（而非先设计技能再拼凑）
```

---

### 3. 整体应用

#### 战斗节奏曲线
```
压力
  ↑
  │    难招      大招
  │     /\       /\
  │    /  \     /  \
  │   /    \___/    \
  │  / 偷袭招       \
  │ /                \
  │/白给招→白给招→白给招\
  └──────────────────→ 时间
```

#### 设计原则
- **白给招**：基础节奏，占比较高（40-50%）
- **偷袭招**：调剂新鲜感，穿插使用（20-30%）
- **难招**：制造压力，稀少但关键（10-20%）
- **大招**：高峰体验，阶段标志（10-15%）

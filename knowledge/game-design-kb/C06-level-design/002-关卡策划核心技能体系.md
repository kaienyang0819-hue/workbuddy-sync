## 核心观点

1. **关卡策划(LD)是"研发中离玩家最近的人"** — 直接构建玩家的空间体验
2. **核心技能三层**: 技术基础(引擎) + 专业理论(设计) + 辅助技能(建筑/语言)
3. **"纸上谈兵"是策划最大的瓶颈** — 不做白盒实践就无法突破
4. **前10个白盒作品都是成长阶梯** — 质量不重要，持续实践才重要

### 关卡设计验证流程
1. **概念**: 纸面设计（俯视图+节奏曲线）
2. **白盒**: 引擎中快速搭建可跑版本
3. **灰盒**: 加入基础美术和光照验证氛围
4. **Playtest**: 找人测试，观察行为而非听反馈
5. **迭代**: 基于测试数据优化

## 设计检查清单

- [ ] **Metrics合规**: 空间尺寸是否符合项目Metrics规范？
- [ ] **动线清晰**: 玩家是否能自然找到前进方向？
- [ ] **节奏交替**: 是否有紧张/放松/紧张的明确节奏？
- [ ] **白盒可玩**: 即使没有美术资源，关卡是否好玩？
- [ ] **Playtest**: 是否让非设计者实际测试过？

## 核心观点

1. **建筑学不只是美术参考，是关卡设计的理论根基** — 视线控制、路径引导、空间叙事都源于建筑学
2. **5000年的建筑史就是5000年的空间UX史** — 从金字塔到万神殿，人类一直在解决"如何引导人在空间中行动"
3. **超越引擎教程，建立空间通用理论** — 高位战略优势适用于FPS/潜行/平台等所有品类
4. **建筑模块语言 = 游戏环境美术的符号系统** — 柱式等级/拱门类型等可转化为游戏视觉语言

## 关键方法论/框架

### 框架一：关卡空间设计三层需求

| 层级 | 需求 | 建筑学对应 | 游戏应用 |
|------|------|-----------|---------|
| **功能性** | 游戏运行基础 | 结构安全 | 碰撞检测/性能优化/可玩区域 |
| **可用性** | 间接引导玩家 | 空间流线 | 视线引导/高低差/轴向布局 |
| **情感性** | 创造氛围体验 | 宗教建筑光影 | 光影控制/空间震撼/探索奖励 |

### 框架二：建筑史→关卡设计的核心映射

| 建筑时期 | 核心原理 | 关卡设计应用 |
|---------|---------|------------|
| **巨石阵** | 天文轴线/视线设计 | 关键物体放在视线轴上引导 |
| **美索不达米亚** | 迂回路径强化叙事 | 非直线路径增加探索深度 |
| **希腊神庙** | 空间序列(前厅→主殿) | 关卡节奏：准备区→战斗区→奖励区 |
| **万神殿** | 外观平凡→内部震撼 | "惊喜设计"：入口不起眼但内部壮观 |
| **中世纪教堂** | 浮雕叙事/朝向引导 | 环境叙事（墙面故事）/目标方向指引 |
| **文艺复兴** | 人体比例系统 | 游戏空间尺度标准（Metrics） |

### 框架三：空间通用理论核心原则

1. **高位=优势**: 高处提供视野/安全感/战略优势（适用于所有品类）
2. **狭窄→开阔=释放**: 从走廊进入大厅的空间释放感（万神殿效应）
3. **轴线=引导**: 视觉轴线上放置目标物，自然引导玩家前进
4. **重复→变化**: 重复建筑元素建立预期，偶尔打破创造惊喜
5. **光=安全/暗=危险**: 人类本能的光暗反应可直接用于关卡氛围

## 设计检查清单

- [ ] **视线轴**: 关键目标是否放在视觉轴线上？
- [ ] **空间节奏**: 是否有狭窄→开阔的空间变化节奏？
- [ ] **高度利用**: 高低差是否被用于战略优势和视野奖励？
- [ ] **比例合理**: 空间尺度是否符合人体比例（Metrics）？
- [ ] **惊喜设计**: 是否有"外观不起眼但进去很壮观"的空间？

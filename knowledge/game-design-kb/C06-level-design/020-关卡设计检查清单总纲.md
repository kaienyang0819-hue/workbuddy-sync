# C6-020 关卡设计检查清单总纲

> **核心观点**：关卡设计终极检查清单,覆盖空间/路径/节奏/机制/叙事/性能六大维度

---
## 六维度检查清单

### 空间设计
- [ ] 尺度是否匹配品类(FPS紧凑/RPG宽敞)?
- [ ] 高低差是否创造战术优势?
- [ ] 开阔与封闭是否有节奏交替?

### 路径设计
- [ ] 是否有至少2条以上通关路径?
- [ ] 隐性引导(光影/坡度)是否到位?
- [ ] 是否避免了"一条路走到黑"?

### 节奏控制
- [ ] 是否有高压→低压→高压交替?
- [ ] 是否有安全区/呼吸空间?
- [ ] 最终BOSS前是否有情绪铺垫?

### 机制设计
- [ ] 是否使用IPMT四步法引入新机制?
- [ ] 机制是否有组合变化(Twist)?
- [ ] 是否每个机制都有清晰教学?

### 叙事融合
- [ ] 环境是否传递了故事信息?
- [ ] 道具是否有叙事符号含义?
- [ ] 关卡情绪是否与剧情同步?

### 性能约束
- [ ] 同屏对象数是否在预算内?
- [ ] 流式加载是否设计?
- [ ] 远景是否有LOD优化?

# 文案策划必修课：从剧情、世界观到情节的具体创作

> **核心观点**：游戏叙事三位一体——世界观（舞台基础）、角色（灵魂载体）、剧情（行动集合）。关键事件必须由玩家主导完成，这是游戏叙事区别于影视/文学的核心差异。

## 方法论

### 世界观构建四大核心模块
1. **基础设定**：题材/世界规则
2. **时间脉络**：关键事件年表
3. **组织架构**：种族/门派设计
4. **空间景观**：地理标志性场景

### 世界观设计三准则
- **认知友好**：如《阴阳师》对日本妖怪文化的现代化重构
- **扩展空间**：预留模糊地带应对版本更新
- **精神内核**：如《荒野大镖客2》对工业文明冲击的反思

### 情节设计四阶强化
1. 日常打破 → 2. 事态升级 → 3. 超常变化 → 4. 倒计时压力

### 角色塑造三维度+情感培养五步
- **三维度**：表层标签 → 深层动机 → 成长弧线
- **五步法**：惊艳亮相→共同经历→秘密共享→主动探索→命运共振

## 案例分析
- **《药神》**：通过吕受益6次铺垫完成剧情转折
- **《天下3》玉玑子**：秩序反抗动机赋予反派深度
- **设计陷阱**：风格矛盾（西幻角色使用中式古语）、无效设定（脱离叙事的世界观冗余）

## 检查清单
- [ ] 世界观四模块是否完整覆盖？
- [ ] 关键事件是否由玩家主导而非观看？
- [ ] 角色是否有表层→深层→弧线三个维度？
- [ ] 剧情节奏是否遵循四阶强化？
- [ ] 单场景是否聚焦单一核心事件（避免信息过载）？

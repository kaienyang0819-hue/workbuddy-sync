# 叙事设计检查清单总纲

> **核心观点**：叙事设计是一个系统工程，需要从世界观构建→角色塑造→剧情编织→环境叙事→商业化适配→本地化六个维度进行完整检查。本卡片汇总C7全部知识，形成可执行的叙事设计检查体系。

## 六维叙事检查体系

### 1. 世界观构建
- [ ] 是否有"三位一体"（玩法-叙事-美术）统一体验？
- [ ] 是否有清晰的主题公式："因[思想]故[状态]"？
- [ ] 文化母体选择是否与目标受众匹配？
- [ ] 幻想偏移路径是否独特且可理解？
- [ ] 是否有"高概念支柱"作为视觉和逻辑锚点？
- [ ] 命名体系是否包含可解读的文化隐喻？

### 2. 角色塑造
- [ ] 角色是否有三维度（表层标签→深层动机→成长弧线）？
- [ ] 情感培养是否遵循五步法（亮相→经历→秘密→探索→共振）？
- [ ] 伙伴角色是否有独立观点（非工具人）？
- [ ] 二游角色是否平衡了商业化与叙事一致性？
- [ ] 角色气质能否在3秒内传达？

### 3. 剧情编织
- [ ] 关键事件是否由玩家主导完成？
- [ ] 节奏是否遵循四阶强化（打破→升级→超常→倒计时）？
- [ ] 单场景是否聚焦单一核心事件？
- [ ] 碎片化叙事是否有系统支撑（非随意堆砌）？
- [ ] 是否保留30%未解谜题激发探索？

### 4. 环境叙事
- [ ] 场景是否同时使用直接+间接叙事？
- [ ] 地貌是否反映世界观中的冲突？
- [ ] 是否有环境叙事检查清单（道具/涂鸦/符号）？
- [ ] 新场景是否与已有事件保持延续？

### 5. 商业化适配
- [ ] 赛年/版本是否有统一叙事主题？
- [ ] 叙事是否"不打扰"核心玩法？
- [ ] 异格/皮肤设计是否与角色叙事一致？
- [ ] 是否有社区二创补充叙事的生态？

### 6. 本地化与AI工具
- [ ] 本地化是否在文字/文化/体验三层适配？
- [ ] 是否建立了文案工程的AI辅助工具链？
- [ ] AI规则文件是否明确了风格边界？
- [ ] 是否有自动化的叙事逻辑一致性检查？

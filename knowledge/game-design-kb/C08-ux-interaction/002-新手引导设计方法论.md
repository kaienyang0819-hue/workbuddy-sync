## 核心观点

1. **最好的引导是让玩家觉得"自己发现"的** — 而非被强制教学
2. **任天堂四步教学法**: 安全环境展示→低风险尝试→组合应用→考验掌握
3. **新手引导的敌人是"信息过载"** — 每次只教一件事

## 关键方法论

### 任天堂四步教学法（每个新机制）

| 步骤 | 方法 | 马里奥案例 |
|------|------|-----------|
| 1. **安全展示** | 在无风险环境首次接触 | 第一个蘑菇放在必经路上 |
| 2. **低风险尝试** | 允许失败但代价小 | 第一个深坑旁有地面可站 |
| 3. **组合应用** | 与已学机制结合 | 跳跃+敌人+平台同时出现 |
| 4. **考验掌握** | 高风险检验 | 连续精确跳跃关卡 |

### 引导方式频谱

```
显性强制 ←──────────────────────→ 隐性自然
弹窗教程   手把手   提示UI   环境暗示   纯发现
(最差)    (常见)   (及格)   (优秀)    (极致)
```

### 信息披露节奏

- **首次登录(0-5分钟)**: 只教核心操作（移动+攻击）
- **前30分钟**: 逐步解锁基础系统（装备/技能/商店）
- **前2小时**: 核心循环完整体验一遍
- **首日**: 所有日常系统开放
- **首周**: 全部系统解锁

## 设计检查清单

- [ ] **一次一件事**: 每个教学步骤是否只教一个概念？
- [ ] **安全环境**: 新机制首次出现时是否无死亡风险？
- [ ] **可跳过**: 老玩家是否可以跳过教程？
- [ ] **隐性优先**: 能用环境暗示的是否用了弹窗？

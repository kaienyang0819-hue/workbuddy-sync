# 隐性引导设计：COCOON解谜案例

> **核心观点**：最好的引导是玩家"感觉不到被引导"。隐性引导通过环境暗示（光线/色彩/声音/空间约束）替代显性UI提示，让玩家在探索中自然习得规则，保持沉浸感。

## 方法论

### 引导设计光谱
```
强显性 ←——————→ 强隐性
箭头指示 > 文字提示 > NPC对话 > 环境暗示 > 空间约束
打断沉浸                              保持沉浸
```

### 隐性引导六大手法
1. **光线引导**：高亮目标区域，暗化无关区域
2. **色彩对比**：可交互物体用鲜明色彩标识
3. **空间约束**：用地形自然限制玩家行走路线
4. **声音诱导**：远处的声音引起好奇心
5. **运动吸引**：移动的物体/NPC引导视线
6. **节奏留白**：安静区域后突然出现的新元素

### 新手引导的渐进原则
- **教一个用一个**：每次只教一个新机制
- **做中学**：通过安全的操作练习而非文字说明
- **失败成本低**：前期错误不惩罚，鼓励尝试
- **重复强化**：新机制在后续关卡中反复出现

## 检查清单
- [ ] 是否优先使用隐性引导而非显性提示？
- [ ] 每个新机制是否有安全的练习空间？
- [ ] 环境引导是否自然（光/色/声/空间）？
- [ ] 玩家是否"感觉不到被引导"？

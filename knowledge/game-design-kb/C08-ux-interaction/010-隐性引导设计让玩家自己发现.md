# 隐性引导设计：让玩家"自己发现"

> **核心观点**：最好的引导是玩家感觉不到被引导。隐性引导通过环境暗示（光线/色彩/声音/构图）代替UI提示，让玩家在"自主探索"的错觉中被精确引导到目标位置。

## 方法论

### 隐性引导五种手段
1. **光线引导**：高亮目标区域，暗化非关键区域（如蜡烛/篝火标记路径）
2. **色彩引导**：高饱和色标记互动物品，低饱和色做环境底色
3. **构图引导**：利用透视线/框景/引导线指向目标
4. **声音引导**：方向性音效暗示目标位置（如远处的钟声）
5. **运动引导**：NPC行走路线/动物逃跑方向指向关键路径

### 显性vs隐性引导的选择
| 场景 | 适合显性引导 | 适合隐性引导 |
|------|-----------|-----------|
| 核心玩法教学 | ✅ 新机制初次出现 | ❌ |
| 路径导航 | ⚠️ 开放世界任务指引 | ✅ 线性关卡路径 |
| 谜题提示 | ❌ 破坏解谜乐趣 | ✅ 环境暗示 |
| 紧急操作 | ✅ QTE/危险警告 | ❌ |

### 黑神话悟空关卡引导分析
- 利用地形高低差和视觉引力引导路径
- NPC/敌人分布暗示前进方向
- 存在部分引导不足的瑕疵（某些分叉路迷路）

## 检查清单
- [ ] 线性路径是否使用隐性引导而非箭头？
- [ ] 互动物品是否有色彩/光线区分？
- [ ] 谜题提示是否通过环境暗示而非直接告知？
- [ ] 隐性引导失败时是否有显性兜底？

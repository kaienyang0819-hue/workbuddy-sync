# 射击手感设计方法论：从Gunplay到体感

> **核心观点**：好的射击手感是"视觉+听觉+触觉+动觉"四维感官的协同设计。不是单独调好后坐力或音效就行，而是整个反馈链条的每个环节都要精确配合。

## 方法论

### 射击手感四维模型
| 维度 | 要素 | 关键参数 |
|------|------|---------|
| **视觉** | 准星扩散/枪口火光/弹壳/弹痕/命中标记 | 扩散恢复曲线/粒子密度 |
| **听觉** | 射击音效/命中音/环境混响/换弹声 | 音频层次/距离衰减 |
| **触觉** | 手柄振动/扳机阻力/脉冲模式 | 振动频率/持续时长 |
| **动觉** | 相机震动/武器动画/角色后仰 | 相机punch值/恢复速度 |

### 手感调试流程
1. **基础射击循环**：开火→后坐力→恢复（最核心的手感来源）
2. **命中反馈链**：射击→弹道飞行→命中标记→伤害数字→击杀确认
3. **武器差异化**：步枪（稳定连射）vs 霰弹（爆裂冲击）vs 狙击（精确单发）
4. **环境响应**：不同材质的弹孔/穿透/反弹效果

### 手感≠写实
- 现代FPS趋势：手感>写实（"真实手感"已过时）
- 竞技游戏需要"干净"的手感（减少干扰信息）
- 娱乐游戏需要"爽快"的手感（夸张反馈）

## 检查清单
- [ ] 四维感官（视/听/触/动）是否协同设计？
- [ ] 命中反馈链是否完整且即时？
- [ ] 不同武器是否有差异化手感？
- [ ] 手感风格是否与游戏调性匹配？

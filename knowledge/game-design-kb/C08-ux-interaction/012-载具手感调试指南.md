# 载具手感调试指南

> **核心观点**：载具手感没有"教科书"，但有通用的调试经验：让大部分玩家能接受→愿意学习→感到掌控。核心是"操作响应曲线"的调优——太灵敏=失控感，太迟钝=笨重感。

## 方法论

### 载具手感三要素
1. **转向响应**：方向盘/摇杆输入→车辆转向的映射曲线
2. **速度体感**：速度数值→玩家感知速度的视觉/音频放大
3. **碰撞反馈**：撞击→视觉震动+音效+速度损失的综合感受

### 调试黄金法则
- **低速灵活，高速稳定**：速度越快转向越迟钝（防失控）
- **视觉速度>实际速度**：FOV随速度增大+动态模糊=更快感
- **容错设计**：碰撞墙壁不死→减速+弹开（降低挫败感）
- **物理vs手感**：100%物理模拟≠好手感，需要"作弊"参数

### 不同载具类型调性
| 类型 | 调性 | 关键调试 |
|------|------|---------|
| 赛车 | 精确/竞技 | 转向响应曲线/漂移手感 |
| 军事载具 | 厚重/有力 | 加速惯性/转向延迟/炮塔独立 |
| 飞行器 | 自由/灵活 | 升降手感/翻滚限制/自动稳定 |

## 检查清单
- [ ] 低速/高速的操控感是否合理差异化？
- [ ] 视觉速度是否通过FOV/模糊增强？
- [ ] 碰撞反馈是否合理（不过于惩罚）？
- [ ] 是否在物理精确和手感好之间找到平衡？

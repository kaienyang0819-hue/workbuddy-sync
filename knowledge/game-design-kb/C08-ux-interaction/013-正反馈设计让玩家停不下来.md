# 正反馈设计：让玩家"停不下来"

> **核心观点**：好的正反馈设计让玩家感受到"每一步都在变强"。《球比伦》案例证明：通过持续不断的新鲜感刺激+密集的成长反馈，可以创造极致心流体验，实现2周破百万销量。

## 方法论

### 正反馈设计五层次
1. **即时反馈**：每次操作都有视听响应（0.1秒内）
2. **短期奖励**：每局/每关都有可感知的成长（1-5分钟）
3. **中期里程碑**：每个session都有新解锁（30-60分钟）
4. **长期目标**：每个阶段都有追求的终极奖励（数小时-数天）
5. **涌现惊喜**：偶尔的超预期奖励打破玩家适应性

### 反馈强度调节
- **频率递减**：前期高频→后期低频（避免通胀）
- **质量递增**：后期奖励品质更高补偿频率下降
- **变量注入**：固定奖励+随机奖励组合（可变比率强化）

### 新内容解锁节奏
- 前20小时（精华期）：密集投放新内容解锁
- 核心循环建立后：深度系统逐步开放
- 末期：社交/竞技/UGC延长寿命

## 检查清单
- [ ] 每次操作是否有即时反馈（<0.1秒）？
- [ ] 每局是否有可感知的成长？
- [ ] 前20小时的新内容解锁是否密集？
- [ ] 奖励频率是否随进度适当递减？

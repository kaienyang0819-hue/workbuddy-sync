# 游戏动效设计原则：12条动画法则的游戏应用

> **核心观点**：迪士尼12条动画法则同样适用于游戏UI动效设计。挤压拉伸/预备动作/缓入缓出/夸张/次要动作等原则让游戏界面从"能用"变成"好用且有趣"。

## 方法论

### 游戏动效核心六则
1. **缓入缓出(Ease)**：所有运动都有加速和减速，避免线性移动
2. **预备动作(Anticipation)**：按钮按下前的微缩/菜单弹出前的蓄力
3. **夸张(Exaggeration)**：获得稀有物品的爆炸特效远大于普通物品
4. **次要动作(Secondary)**：主角色移动时，背包/头发/披风的跟随摆动
5. **时间控制(Timing)**：快=轻/锐,慢=重/庄重；用速度传达情绪
6. **弧线运动(Arcs)**：UI元素沿弧线而非直线移动更自然

### 动效三大功能
- **引导**：用动效引导视线到关键信息
- **反馈**：用动效确认操作已被识别
- **情绪**：用动效传递情感基调（开箱的期待/升级的喜悦）

### 动效性能预算
- 移动端：动效帧率≥30fps,总GPU占用≤5%
- 关键路径动效不超过0.3秒（避免阻塞操作）
- 可在设置中关闭非必要动效

## 检查清单
- [ ] UI动效是否有缓入缓出（非线性运动）？
- [ ] 重要操作是否有预备+反馈动效？
- [ ] 动效是否服务于引导/反馈/情绪功能？
- [ ] 动效是否有性能预算控制？

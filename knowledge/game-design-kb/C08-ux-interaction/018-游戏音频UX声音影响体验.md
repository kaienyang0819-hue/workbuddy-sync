# 游戏音频UX：声音如何影响体验

> **核心观点**：游戏音频不只是"背景音乐+音效"，而是UX设计的重要维度。声音可以传递信息（方向/距离/危险程度）、引导行为（注意力/情绪）、强化反馈（操作确认/状态变化）。

## 方法论

### 游戏音频三大功能
1. **信息传递**：3D空间音频告知敌人方向/距离
2. **情绪塑造**：音乐调性控制紧张/放松/悲伤/兴奋
3. **反馈强化**：操作音效确认+状态变化提示

### 音频UX设计要点
- **分层混音**：BGM/环境音/UI音/战斗音分层管理
- **动态音乐**：根据游戏状态无缝切换音乐（探索→战斗→胜利）
- **空间音频**：FPS/恐怖游戏必备——声音方向=关键信息
- **音频疲劳管理**：避免重复音效引发烦躁

### UI音效设计原则
- 按钮点击：短促/清脆/低音量
- 确认操作：上升音调=正向/下降音调=负向
- 错误提示：温和提醒而非刺耳警报
- 获得奖励：渐进升调+和弦=喜悦感

## 检查清单
- [ ] 是否有分层混音管理？
- [ ] BGM是否根据游戏状态动态切换？
- [ ] 空间音频是否能传递方向信息？
- [ ] UI音效是否反映了操作正/负结果？

# 游戏设置菜单设计最佳实践

> **核心观点**：设置菜单是"最不性感但最影响留存"的UI——糟糕的设置导致玩家直接卸载。画质/操控/音频/社交四大类设置需要合理分组，关键选项需要预览功能。

## 方法论

### 设置菜单四大类
| 类别 | 核心选项 | 设计要点 |
|------|---------|---------|
| **画质** | 分辨率/帧率/特效等级 | 需要实时预览+自动推荐配置 |
| **操控** | 灵敏度/按键映射/辅助 | 需要校准工具+预设方案 |
| **音频** | 主音量/BGM/音效/语音 | 需要独立滑条+试听功能 |
| **社交** | 隐私/屏蔽/通知 | 需要一键静默模式 |

### 设置菜单UX原则
1. **自动推荐**：首次启动自动检测并推荐最优配置
2. **分级展示**：常用设置置顶，高级设置折叠
3. **实时预览**：修改画质/灵敏度时立即可见效果
4. **一键恢复**：提供"恢复默认"避免玩家搞乱设置
5. **记忆导入**：支持跨设备/跨账号导入设置

## 检查清单
- [ ] 首次启动是否有自动配置推荐？
- [ ] 画质设置是否有实时预览？
- [ ] 灵敏度是否有校准工具？
- [ ] 是否有"恢复默认"选项？

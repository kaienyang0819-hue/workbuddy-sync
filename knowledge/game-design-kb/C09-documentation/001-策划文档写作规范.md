## 核心观点

1. **好文档=团队可直接执行** — 如果程序/美术看完还需要反复确认，文档就是失败的
2. **策划案五大标准模块**: 背景·内容概要·详细设计·数据目标·排期
3. **详细设计三段式**: "是什么→怎么做→边界问题"——每个功能点必须覆盖
4. **AI正在改变文档工作流** — AI生成初稿+人工审核精修，效率提升100倍（OpenClaw案例）

## 关键方法论

### 策划案标准结构

| 模块 | 必须回答的问题 |
|------|--------------|
| **背景** | 为什么做这个？解决什么问题？ |
| **内容概要** | 做什么？核心玩法一句话描述 |
| **详细设计** | 怎么做？规则/流程/异常处理 |
| **数据目标** | 做到什么程度？量化标准 |
| **排期** | 多久做完？里程碑节点 |

### 详细设计三段式

每个功能点：
1. **是什么**: 功能定义、核心规则
2. **怎么做**: 交互流程、状态转换、公式参数
3. **边界问题**: 异常情况、极端case、与其他系统的冲突

### 文档写作检查清单

- [ ] 程序看完是否能直接开始写代码？
- [ ] 美术看完是否知道要出什么资源？
- [ ] 是否有明确的验收标准？
- [ ] 异常情况是否都有处理方案？
- [ ] 与其他系统的交互是否说清了？

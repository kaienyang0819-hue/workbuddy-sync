# 数值策划文档规范

> **核心观点**：数值文档的核心是"可验证性"——每个数值背后都要有公式/依据/推导过程，让其他人能验算正确性，也让未来的自己能理解当初的设计意图。

## 方法论

### 数值文档标准结构
1. **设计目标**：这组数值要达成什么体验目标？
2. **核心公式**：展示完整公式和参数含义
3. **参数配置表**：所有可调参数+默认值+取值范围
4. **推导过程**：为什么选这个值？基于什么假设？
5. **模拟验证**：关键场景的模拟计算结果
6. **调优指南**：如果效果不理想，调哪个参数？

### 数值表格规范
- **必填列**：ID/名称/参数值/说明/公式引用
- **可选列**：修改日期/修改人/修改原因
- **颜色编码**：蓝色=手动配置，黄色=公式计算，红色=待确认
- **版本对比**：保留历史版本便于回溯

### Excel策划表最佳实践
- Sheet1: 配置总览（导出给程序用）
- Sheet2: 公式推导（设计思路和计算过程）
- Sheet3: 模拟验证（典型场景模拟）
- Sheet4: 版本记录（变更历史）

## 检查清单
- [ ] 每个数值是否有公式/依据？
- [ ] 参数取值范围是否明确？
- [ ] 是否有模拟验证关键场景？
- [ ] 是否有调优指南说明如何调整？

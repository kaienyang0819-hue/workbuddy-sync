# 竞品分析报告写作方法

> **核心观点**：竞品分析不是"功能罗列"而是"差异洞察"——好的竞品分析回答的是"竞品为什么这么做"和"我们能学到什么"，而非"竞品有什么功能"。

## 方法论

### 竞品分析报告结构
1. **分析目标**：为什么做这次分析？要回答什么问题？
2. **竞品选择**：为什么选这几款？（直接竞品/间接竞品/标杆产品）
3. **维度拆解**：从哪些维度对比？
4. **差异洞察**：核心差异在哪里？为什么？
5. **可借鉴点**：哪些做法值得我们学习？
6. **行动建议**：具体建议和优先级

### 竞品拆解维度
| 维度 | 分析要点 |
|------|---------|
| **核心循环** | 核心玩法+反馈循环+成长曲线 |
| **商业化** | 付费模型+定价策略+转化漏斗 |
| **用户画像** | 目标用户+DAU/MAU+留存曲线 |
| **差异化** | 独特卖点+市场定位+品牌调性 |
| **技术方案** | 引擎/网络/画面表现 |

### 常见错误
- ❌ 只列功能不分析原因
- ❌ 只看表面不深挖数据
- ❌ 有洞察无行动建议
- ❌ 竞品选择无标准

## 检查清单
- [ ] 分析目标是否明确（回答什么问题）？
- [ ] 是否有"为什么"的深层洞察？
- [ ] 是否有具体可执行的行动建议？
- [ ] 竞品选择是否有合理依据？

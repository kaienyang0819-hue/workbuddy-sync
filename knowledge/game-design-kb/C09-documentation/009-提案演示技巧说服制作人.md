# 提案演示技巧：如何说服制作人

> **核心观点**：好的设计不等于好的提案——策划案通过率取决于"你能否在5分钟内让决策者理解价值并产生兴趣"。核心技巧：先讲Why（为什么做）→再讲What（做什么）→最后讲How（怎么做）。

## 方法论

### 提案金字塔结构
1. **Hook（30秒）**：一句话核心卖点/问题陈述
2. **Why（1分钟）**：为什么现在要做这个？数据/痛点/机会
3. **What（2分钟）**：核心方案是什么？关键差异在哪？
4. **How（1分钟）**：实现路径+资源需求+时间估算
5. **Risk（30秒）**：主要风险+应对方案

### 说服三要素
- **逻辑**：数据支撑+因果推理+对比论证
- **情感**：玩家痛点故事+愿景描绘+demo体验
- **可信**：竞品验证+团队能力+里程碑计划

### 提案PPT设计
- 每页一个核心信息
- 图表>文字，数字>形容词
- 10页以内，20分钟以内
- 准备3倍于展示内容的backup页

### 常见失败原因
- 没讲清"为什么"就直接讲方案
- 方案太理想化没有落地路径
- 对风险和成本避而不谈
- 展示太长，失去听众注意力

## 检查清单
- [ ] 30秒内能否讲清核心卖点？
- [ ] Why-What-How结构是否清晰？
- [ ] 是否有数据支撑而非纯主观判断？
- [ ] 风险和成本是否坦诚说明？

# 用户研究报告写作规范

> **核心观点**：用研报告要"数据驱动+用户故事+行动建议"三位一体——纯数字没有温度，纯故事没有说服力，没有建议没有价值。

## 方法论

### 用研报告标准结构
1. **执行摘要**：核心发现+关键建议（1页）
2. **研究背景**：目标/方法/样本/时间
3. **定量发现**：数据图表+统计分析
4. **定性洞察**：用户访谈引用+行为观察
5. **问题清单**：按严重性排序的体验问题
6. **行动建议**：针对每个问题的具体改进方案+优先级
7. **附录**：原始数据/问卷/访谈记录

### 数据可视化原则
- 趋势用折线图，对比用柱状图，占比用饼图
- 一图一观点，标题直接写结论
- 标注关键转折点和异常值
- 颜色有含义（红=问题，绿=正向）

### 用户引用技巧
- 选择有代表性的引用（非极端个例）
- 引用后必须跟分析解读
- 保护用户隐私（匿名化处理）

## 检查清单
- [ ] 执行摘要是否1页内讲清核心发现？
- [ ] 每个发现是否有数据+用户故事双重支撑？
- [ ] 问题是否按严重性排序？
- [ ] 每个问题是否有具体行动建议？

# Excel策划表设计规范

## 核心观点
Excel是策划的第二语言。配置表的设计质量直接影响开发效率和出错率。好的Excel规范能让程序一目了然地读取数据，让QA高效验证，让策划自己不会在3个月后看不懂。

## 方法论

### 表结构三层模型
1. **表头层（Row 1-3）**：字段中文名 / 字段英文名(程序用) / 字段类型+约束
2. **数据层（Row 4+）**：实际配置数据
3. **注释层（隐藏列/Sheet）**：填表说明、枚举值定义、公式计算

### 命名规范
- **Sheet名**：`模块名_子功能`，如 `Hero_Skill`, `Shop_Item`
- **字段名**：小驼峰（camelCase），如 `skillDamage`, `cooldownTime`
- **ID规则**：模块前缀+自增，如 `HERO_001`, `SKILL_10001`
- **枚举值**：用英文常量，如 `PHYSICAL/MAGICAL/TRUE`，不要用1/2/3

### 数据验证
- **下拉列表**：枚举字段必须用数据验证限制可选值
- **条件格式**：异常数据红色高亮（如负数生命值、超限概率）
- **公式校验**：概率总和=100%、经验曲线单调递增等
- **引用完整性**：外键ID必须在对应主表中存在

### 协作规范
- **锁定表头**：冻结前3行，防止误修改
- **保护公式列**：计算列锁定，只允许修改输入列
- **变更日志Sheet**：记录每次改动的人/时间/内容
- **颜色语义**：黄色=待确认，绿色=已验证，红色=有问题

### 常见陷阱
- 合并单元格：**绝对禁止**，程序无法解析
- 空行空列：数据区域中间不能有空行
- 特殊字符：避免换行符、制表符、全角空格
- 浮点数精度：货币/概率用整数（分/万分比）

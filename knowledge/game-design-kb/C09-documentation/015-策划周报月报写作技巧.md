# 策划周报/月报写作技巧

## 核心观点
周报月报不是"应付差事"的流水账，而是向上管理和自我复盘的重要工具。好的周报能让上级快速了解进展和风险，帮自己理清思路、沉淀方法。

## 方法论

### 周报PREP框架
- **P(Progress)**：本周完成了什么（量化，如"完成3个系统设计文档"）
- **R(Risk)**：遇到什么风险/阻塞（提前暴露，不要藏着）
- **E(Expectation)**：下周计划做什么（对齐预期）
- **P(Proposal)**：需要什么支持/资源（主动争取）

### 月报升维
在周报基础上增加：
- **数据复盘**：功能上线后的数据表现（DAU/留存/付费变化）
- **方法沉淀**：本月学到什么可复用的方法论
- **竞品动态**：行业有什么值得关注的变化
- **下月目标**：OKR对齐，量化可衡量

### 写作技巧
1. **结论先行**：第一句话说最重要的事
2. **量化表达**：用数字代替形容词（"优化了体验"→"通关率从32%提升到47%"）
3. **分层结构**：标题→要点→详情，方便速读
4. **风险前置**：把风险放在靠前位置，不要埋在最后

### 反面教材
- "本周正常推进" → 完全没有信息量
- 流水账式罗列 → 没有重点和结论
- 只报好消息 → 风险积累到爆炸

## 检查清单
- [ ] 是否有量化的进度描述
- [ ] 风险和阻塞是否明确列出
- [ ] 下周计划是否具体可执行
- [ ] 是否有需要支持的事项
- [ ] 篇幅是否控制在5分钟可读完

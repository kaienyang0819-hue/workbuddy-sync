# AI辅助策划文档生产力革命

## 核心观点
AI（LLM/Copilot）正在改变策划文档的生产方式。从"人写文档"到"人指导AI写文档"，效率可提升3-5倍。但核心的设计决策仍然需要人类策划的判断力。

## 方法论

### AI在文档工作流中的角色
| 环节 | AI能力 | 人类角色 |
|------|--------|----------|
| 脑暴 | 快速生成大量创意 | 筛选、组合、判断 |
| 初稿 | 根据提纲生成完整文档 | 审查逻辑、补充细节 |
| 格式化 | 自动套用模板+排版 | 确认规范合规 |
| 翻译/本地化 | 快速多语言转换 | 文化适配审查 |
| 数据分析 | 快速统计+可视化 | 解读洞察+决策 |

### 高效Prompt策略
1. **角色设定**："你是一个有10年经验的系统策划"
2. **结构要求**："按照以下格式输出：需求背景/核心机制/数值设计/边界处理"
3. **约束条件**："目标用户是休闲玩家，付费深度不超过68元"
4. **迭代反馈**："第二点的数值不合理，帕鲁的捕获率应该…"

### AI文档质量保障
- **幻觉检测**：AI生成的数据/引用必须人工验证
- **一致性检查**：AI可能在同一文档中产生矛盾描述
- **专业度校准**：AI的"行业经验"来自训练数据，可能过时
- **版权风险**：AI生成内容可能无意中复制受保护内容

### 工具链
- **game-design-doc-template**：Excel策划文档标准化生成
- **mygamedesignhelper**：全流程策划工作流（脑暴→定稿）
- **agf-quality-gate**：自动质量门禁检查
- **Cursor/Windsurf/WorkBuddy**：IDE级AI辅助开发

## 案例
- **AI IDE辅助叙事设计**：用LLM批量生成NPC对话，人工精调关键节点
- **自动化竞品分析**：AI爬取+结构化+初步分析，人工深度解读

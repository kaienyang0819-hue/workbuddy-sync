# 文档表达能力检查清单总纲

## 核心观点
策划的文档能力是最容易被低估但影响最大的能力。一个系统设计再好，如果文档写不清楚，程序做出来的东西就不是你想要的。本卡片汇总C09全部20张卡片的核心检查项，形成策划文档终极自检清单。

## 总纲检查清单

### 一、文档结构（Structure）
- [ ] 有清晰的目录/导航结构
- [ ] 标题层级不超过4级
- [ ] 复杂逻辑配有可视化图表
- [ ] 每个章节都能独立阅读

### 二、内容完整性（Completeness）
- [ ] 需求背景和目标明确
- [ ] 所有功能点/规则都已覆盖
- [ ] 异常/边界情况已处理
- [ ] 可配置参数已提取为数据表

### 三、表达精确性（Precision）
- [ ] 无模糊描述（"大约""一些""合适"）
- [ ] 数值全部精确到具体数字
- [ ] 枚举值全部列出
- [ ] 规则无二义性

### 四、可执行性（Actionability）
- [ ] 程序无需额外沟通就能开发
- [ ] 美术无需猜测就能制作
- [ ] QA可以直接编写测试用例
- [ ] 运营能理解功能概述

### 五、规范性（Standards）
- [ ] 格式符合团队文档模板
- [ ] 命名遵循团队规范
- [ ] 版本号/变更记录完整
- [ ] 附件/引用链接有效

### 六、协作性（Collaboration）
- [ ] 评审意见已回复处理
- [ ] 跨部门对齐点已标注
- [ ] 关键假设显式说明
- [ ] 文档已同步给所有相关方

### 七、效率（Efficiency）
- [ ] 重复性工作已用工具/AI辅助
- [ ] 周报月报有量化表达
- [ ] 文档可被自动化工具处理

## 能力评估维度
| 级别 | 描述 |
|------|------|
| Lv.1 入门 | 能写出基本完整的策划文档 |
| Lv.3 应用 | 文档结构清晰，规则无二义性 |
| Lv.5 精通 | 能针对不同受众写不同版本，善用可视化 |
| Lv.7 专业 | 建立团队文档规范，用AI提效，指导新人 |

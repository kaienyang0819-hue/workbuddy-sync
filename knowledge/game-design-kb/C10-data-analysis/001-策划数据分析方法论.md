## 核心观点

1. **数据不是目的，验证设计假设才是** — 策划看数据不是为了写报告，是为了回答"我的设计对不对"
2. **核心指标金字塔**: DAU→留存→付费→LTV，层层递进
3. **漏斗分析是发现问题的利器** — 每一步的流失率都指向一个设计问题
4. **沉默证据比投诉更危险** — 30%潜在流失用户从不反馈（王者荣耀案例）

## 关键方法论/框架

### 框架一：策划核心指标金字塔

```
            LTV
           (生命周期价值)
          ┌─────┐
         │ ARPU │ ← 每活跃用户收入
        ┌─────────┐
       │  付费率   │ ← 付费玩家/活跃玩家
      ┌─────────────┐
     │ 留存(次留/7留) │ ← 核心健康指标
    ┌─────────────────┐
   │    DAU / MAU      │ ← 活跃规模
  ┌─────────────────────┐
 │  新增/回流/自然流量    │ ← 用户来源
└─────────────────────────┘
```

### 框架二：策划最常用的五种分析方法

| 方法 | 回答什么问题 | 典型应用 |
|------|------------|---------|
| **漏斗分析** | 用户在哪一步流失了？ | 新手引导流失点、付费转化链路 |
| **留存分析** | 用户留下来了吗？为什么？ | 次留/7留/30留趋势、版本更新效果 |
| **分群对比** | 不同群体有什么差异？ | 付费vs非付费、新手vs老手 |
| **AB测试** | 方案A和B哪个更好？ | 新功能效果验证、定价测试 |
| **行为路径** | 用户在做什么？ | 核心循环是否符合设计预期 |

### 框架三：AB测试设计要点

1. **单变量**: 每次只改一个变量
2. **样本量**: 确保统计显著性（p<0.05）
3. **时间窗**: 至少跑7天覆盖完整周循环
4. **核心指标**: 预先定义北极星指标，避免看太多指标导致"总能找到一个好的"
5. **边际效益**: 识别优化的边际拐点（王者荣耀"温暖局投放"案例）

### 关键认知：沉默证据法则

- **来源**: 王者荣耀系统设计复盘
- **内容**: 30%潜在流失用户从不投诉/反馈
- **方法**: 用"赛季染色图"（段位驻留监控）主动发现
- **启示**: 不能只看反馈数据，要主动构建"无声流失"的监测机制

## 设计检查清单

- [ ] **北极星指标**: 当前版本的核心优化指标是什么？
- [ ] **漏斗完整**: 关键流程是否建立了完整的漏斗监控？
- [ ] **AB测试**: 重大改动是否通过AB测试验证？
- [ ] **沉默用户**: 是否有机制发现"不投诉但在流失"的用户？
- [ ] **数据复盘**: 每次版本更新后是否有数据复盘？

## 核心框架

### 竞品分析七维度

| 维度 | 分析内容 | 关注点 |
|------|---------|--------|
| **核心循环** | 30秒/分钟/日循环结构 | 什么让玩家"再来一局" |
| **系统架构** | 所有系统及其关联关系 | 系统间如何互相驱动 |
| **数值体系** | 成长曲线/经济模型/平衡性 | 养成节奏和付费深度 |
| **商业化** | 付费模型/定价/SKU | 怎么赚钱/赚谁的钱 |
| **UX/交互** | 新手引导/HUD/操作 | 上手门槛和信息传达 |
| **技术表现** | 画面/帧率/网络/加载 | 技术竞争力 |
| **社区/生态** | 用户口碑/社区活跃度 | 长线生命力 |

### 竞品报告标准模板

```
1. 产品概述（品类/平台/上线时间/团队）
2. 核心循环拆解
3. 七维度逐项分析
4. SWOT总结
5. 对我方产品的启示
6. 可借鉴的设计点（附具体案例）
```

## 设计检查清单

- [ ] 是否覆盖了七个维度？
- [ ] 核心循环是否亲自玩到？（非看视频）
- [ ] 分析结论是否有"对我方的具体启示"？

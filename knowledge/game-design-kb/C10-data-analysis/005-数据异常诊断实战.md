## 核心框架

### 数据异常诊断五步法

```
1. 发现异常 → 什么指标在什么时间偏离了预期？
2. 定位范围 → 是全局还是某个渠道/版本/人群？
3. 归因分析 → 是产品变更/外部因素/技术故障？
4. 验证假设 → 用对照组或历史数据验证归因
5. 输出建议 → 具体的优化行动+预期效果
```

### 版本效果评估模板

| 维度 | 观察指标 | 判定标准 |
|------|---------|---------|
| **活跃影响** | DAU/MAU/人均时长 | 与预期对比+环比同比 |
| **留存影响** | 新用户次留/7留 | 与版本前基线对比 |
| **付费影响** | ARPU/付费率/付费UV | 区分新老用户 |
| **体验影响** | 好评率/投诉率/NPS | 质变还是微调 |
| **功能使用** | 新功能渗透率/使用频次 | 是否达到设计预期 |

### 王者荣耀数据驱动决策案例（引自C1-004）

- **DAU-AB实验框架**: 识别温暖局投放的边际效益拐点
- **赛季染色图**: 段位驻留监控，发现30%沉默流失
- **体验概率优化**: AI调控使优质体验率63%→81%

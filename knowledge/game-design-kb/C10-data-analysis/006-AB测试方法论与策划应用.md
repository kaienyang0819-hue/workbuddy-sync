# AB测试方法论与策划应用

## 核心观点
AB测试是策划用数据验证设计决策的最科学方法。不是"我觉得A方案好"，而是"数据证明A方案的留存率高3.2个百分点"。掌握AB测试，策划从"靠直觉"升级为"靠数据"。

## 方法论

### AB测试基本原理
- **对照组（Control）**：保持现状不变
- **实验组（Treatment）**：实施改动方案
- **随机分流**：确保两组玩家特征无偏差
- **统计显著性**：结果差异不是随机波动（p<0.05）

### 策划常用AB测试场景
| 场景 | 测试维度 | 核心指标 |
|------|----------|----------|
| 新手引导 | 引导步骤数/方式 | 7日留存率 |
| 付费弹窗 | 弹窗时机/文案/折扣 | 转化率/ARPU |
| 难度曲线 | 关卡难度参数 | 通过率/流失节点 |
| UI布局 | 按钮位置/颜色/大小 | 点击率/误触率 |
| 奖励设计 | 奖励数量/类型/呈现方式 | 领取率/次日回访 |

### AB测试四步法
1. **假设**：明确要验证什么（"将首充奖励从6元降到1元会提升首充率"）
2. **设计**：定义分组/样本量/观测期/核心指标
3. **执行**：分流上线，监控数据异常
4. **分析**：统计显著性检验→结论→决策

### 样本量计算
- **最小样本量**取决于：预期效果大小 × 统计显著性 × 统计功效
- 经验法则：每组至少1000+用户，观测期7-14天
- 小流量游戏：可以用序贯检验（Sequential Testing）提前终止

### 常见陷阱
- **辛普森悖论**：总体数据和分组数据结论相反
- **新奇效应**：新方案短期数据好看只是因为新鲜感
- **多重比较**：同时测试5个指标，至少一个会"碰巧显著"
- **流量污染**：同一玩家看到了两种方案

## 案例
- **Supercell**：每个功能上线前必须AB测试，不通过就砍
- **miHoYo**：原神活动奖励的AB测试优化投放策略

## 检查清单
- [ ] 假设是否明确且可证伪
- [ ] 样本量是否足够
- [ ] 分流是否真随机
- [ ] 观测期是否考虑了周末效应
- [ ] 是否排除了新奇效应

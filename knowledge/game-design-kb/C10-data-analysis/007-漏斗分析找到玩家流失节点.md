# 漏斗分析：找到玩家流失节点

## 核心观点
漏斗分析是定位玩家流失原因的最直接工具。从下载→注册→教程→首战→次留→七留→付费，每一步都有转化率，每一个大幅下降的节点都是需要策划重点优化的地方。

## 方法论

### 核心漏斗模型
```
下载(100%) → 激活(80%) → 注册(65%) → 新手教程完成(45%) 
→ 核心玩法首次(35%) → 次日留存(25%) → 7日留存(12%) 
→ 首充(3%) → 30日留存(5%) → 月活跃付费(1.5%)
```

### 关键转化率基准（手游）
| 节点 | 健康值 | 警戒值 |
|------|--------|--------|
| 激活→注册 | >80% | <60% |
| 注册→教程完成 | >70% | <50% |
| 教程→核心玩法 | >60% | <40% |
| 首日→次日留存 | >40% | <30% |
| 次留→7日留存 | >50% | <35% |
| 首充转化率 | >5% | <2% |

### 流失节点诊断流程
1. **定位**：找到转化率下降最大的节点
2. **分群**：按渠道/设备/新老用户拆分看差异
3. **复现**：自己走一遍玩家路径，感受体验
4. **假设**：列出可能原因（太难/太无聊/加载慢/不理解）
5. **验证**：AB测试或小范围灰度验证假设
6. **优化**：实施改进方案并持续监控

### 漏斗细化技巧
- **时间维度**：区分5分钟内流失 vs 30分钟后流失
- **行为维度**：流失前最后操作是什么
- **设备维度**：低端机流失率是否异常高
- **渠道维度**：买量用户vs自然用户漏斗差异

## 案例
- **新手教程优化**：某手游教程完成率从45%提升到72%，方法是把15步教程砍到6步
- **付费漏斗优化**：某游戏首充转化率从2%→6%，通过在首次卡关后弹出限时礼包

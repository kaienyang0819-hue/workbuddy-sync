# 玩家分群与用户画像构建

## 核心观点
"所有玩家"是个伪概念。不同玩家有不同的行为模式、付费意愿和留存动机。精细化运营的基础是把玩家分成有意义的群组，然后针对性地设计体验和运营策略。

## 方法论

### 经典分群维度
1. **生命周期**：新手/成长/成熟/衰退/流失/回流
2. **付费能力**：鲸鱼(>500元)/海豚(50-500)/小鱼(1-50)/免费
3. **活跃度**：日活/周活/月活/沉默
4. **玩法偏好**：PVP/PVE/社交/收集/探索
5. **技术水平**：新手/中等/高手/职业

### RFM模型在游戏中的应用
- **R(Recency)**：最近一次登录距今天数
- **F(Frequency)**：过去30天登录天数
- **M(Monetary)**：过去30天付费金额

| RFM评分 | 玩家类型 | 运营策略 |
|---------|----------|----------|
| 高R高F高M | 核心VIP | 专属服务+尊享权益 |
| 高R高F低M | 活跃免费 | 首充引导+限时折扣 |
| 低R高F高M | 大R疲劳 | 回流礼包+新内容预告 |
| 低R低F低M | 流失用户 | 召回短信/邮件+回流奖励 |

### 画像构建流程
1. **数据采集**：行为日志+付费记录+设备信息+渠道来源
2. **特征工程**：计算衍生指标（平均session时长/战斗胜率/社交活跃度）
3. **聚类分析**：K-means/层次聚类，找到自然群组
4. **标签体系**：给每个群组起名+定义特征
5. **应用验证**：分群策略AB测试验证效果

### 常见误区
- **标签过多**：100个标签=没有标签，核心维度3-5个足够
- **静态画像**：玩家是会变的，画像需要定期更新
- **忽视长尾**：80%的收入来自20%的用户，但另外80%的用户是口碑传播者

## 案例
- **Steam用户画像分析**：通过游玩时长/成就/评价/好友数构建玩家画像
- **某二次元手游分群运营**：把玩家分成"角色党""战力党""剧情党"，分别推不同活动

## 检查清单
- [ ] 是否建立了核心分群维度
- [ ] 分群结果是否可指导差异化运营
- [ ] 画像是否有定期更新机制
- [ ] 关键分群是否有AB验证

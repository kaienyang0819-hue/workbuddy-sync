# 留存分析方法论与策划应用

## 核心观点
留存率是游戏最核心的健康指标。次留反映首次体验，7留反映核心循环，30留反映长期生命力。策划的每一个设计决策最终都体现在留存曲线上。

## 方法论

### 留存率基准（手游2025）
| 指标 | 优秀 | 良好 | 及格 | 危险 |
|------|------|------|------|------|
| 次日留存 | >45% | >35% | >25% | <20% |
| 7日留存 | >20% | >15% | >10% | <8% |
| 30日留存 | >10% | >7% | >5% | <3% |

### 留存分析三板斧
1. **整体留存曲线**：观察曲线形状（L型/凹型/阶梯型）
2. **分群留存对比**：不同渠道/设备/版本的留存差异
3. **功能留存归因**：使用了X功能 vs 未使用的留存差异

### 留存诊断框架
```
次留下降 → 检查首日体验
├── 加载时间 > 30秒？ → 性能优化
├── 教程完成率 < 50%？ → 简化引导
├── 首次核心玩法触达率 < 40%？ → 缩短前置
└── 首日在线时长 < 10分钟？ → 内容吸引力不足

7留下降 → 检查核心循环
├── 日常任务完成率？ → 任务设计
├── PVP/PVE参与率？ → 内容深度
├── 社交绑定率？ → 社交系统
└── 卡关率？ → 难度曲线

30留下降 → 检查长期动力
├── 进度到达率（开服1个月追上多少内容）
├── 付费渗透率
├── 公会/好友活跃度
└── 版本更新节奏
```

### 留存提升策略优先级
1. 🔴 修复首日体验阻塞点（ROI最高）
2. 🟡 强化核心循环的每日动机
3. 🟡 建立社交关系链
4. 🟢 丰富中长期目标层
5. 🟢 定期内容更新节奏

## 案例
- **和平精英**：通过AI匹配让新手首局就能吃鸡，次留提升8个百分点
- **王者荣耀**：每赛季重置排位+新英雄，维持30日留存长期稳定

# 付费数据分析与商业化优化

## 核心观点
付费数据是游戏商业成功的核心指标体系。策划需要理解从LTV预测到ARPU优化的完整分析链路，才能做出既让玩家满意又让老板满意的商业化设计。

## 方法论

### 付费核心指标矩阵
| 指标 | 定义 | 计算方式 | 基准（手游）|
|------|------|----------|------------|
| ARPU | 每活跃用户收入 | 总收入/DAU | $0.1-0.5 |
| ARPPU | 每付费用户收入 | 总收入/付费人数 | $5-50 |
| 付费率 | 付费用户占比 | 付费人数/DAU | 3%-8% |
| LTV | 用户生命周期价值 | Σ(日均收入×留存率) | 因品类而异 |
| ROI | 投入产出比 | LTV/CPI | >1.0 |
| 首充率 | 首次充值转化 | 首充人数/新增 | 5%-15% |

### LTV预测方法
1. **留存法**：LTV = ARPDAU × Σ(第i天留存率)
2. **对数回归法**：用30天数据拟合对数曲线预测365天LTV
3. **分群预测**：按付费档位/渠道/国家分别预测
4. **机器学习法**：XGBoost等模型预测个体LTV

### 付费漏斗优化
```
曝光(100%) → 点击(30%) → 浏览商品(15%) → 下单(5%) → 支付成功(3%)
```
每一步优化1%，最终效果是乘法叠加。

### 价格策略
- **首充礼包**：超高性价比引导跨过付费门槛（1元/6元）
- **月卡/通行证**：低价高价值的持续付费
- **限时折扣**：制造紧迫感，FOMO心理
- **锚定效应**：先展示高价商品，再展示目标商品

## 案例
- **原神**：低付费率+极高ARPPU的"鲸鱼模型"
- **王者荣耀**：高付费率+低ARPPU的"全民付费模型"

## 检查清单
- [ ] 核心付费指标是否每日监控
- [ ] LTV预测模型是否建立
- [ ] 付费漏斗各环节转化率是否清晰
- [ ] 不同用户群的ARPPU差异是否分析

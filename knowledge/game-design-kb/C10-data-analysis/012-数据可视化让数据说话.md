# 数据可视化：让数据说话

## 核心观点
数据本身没有说服力，可视化才有。策划向制作人汇报时，一张好图胜过十页数据表。掌握数据可视化不是为了好看，而是为了"让正确的信息被正确地感知"。

## 方法论

### 图表选型指南
| 目的 | 推荐图表 | 示例 |
|------|----------|------|
| 趋势变化 | 折线图 | DAU/MAU趋势 |
| 占比分布 | 饼图/环形图 | 各品类收入占比 |
| 对比排名 | 柱状图 | 各服务器活跃对比 |
| 分布密度 | 直方图/箱线图 | 玩家等级分布 |
| 相关关系 | 散点图 | 在线时长vs付费金额 |
| 漏斗转化 | 漏斗图 | 注册→付费转化链 |
| 多维对比 | 雷达图 | 竞品功能对比 |
| 热力分布 | 热力图 | 地图区域玩家密度 |

### 可视化三原则
1. **数据墨水比**：图上每个像素都应传递信息，删除无用装饰
2. **认知负荷**：一张图只传达一个核心信息
3. **诚实原则**：Y轴从0开始，不裁剪不误导

### 策划日报/周报常用图表组合
```
第一屏：关键数字卡片（DAU/收入/新增/留存）
第二屏：趋势折线图（7天DAU+收入叠加）
第三屏：漏斗图（新用户转化）
第四屏：对比柱状图（版本前后/渠道对比）
```

### 工具推荐
- **Excel/Google Sheets**：快速出图，够用
- **Tableau/PowerBI**：交互式仪表盘，适合团队共享
- **Python(Matplotlib/Seaborn)**：精细控制，适合深度分析
- **Grafana**：实时监控大盘

## 检查清单
- [ ] 图表类型是否匹配数据特征
- [ ] 是否有清晰的标题和图例
- [ ] Y轴是否从0开始（除非有特殊理由）
- [ ] 核心信息是否一目了然

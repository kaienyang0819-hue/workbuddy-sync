# 竞品数据分析实战方法

## 核心观点
竞品分析不是写"XX游戏有什么功能"的流水账，而是通过数据对比回答"我们和竞品的差距在哪、为什么、怎么追"。数据驱动的竞品分析是策划立项和版本决策的核心输入。

## 方法论

### 竞品数据采集渠道
| 数据类型 | 来源 | 可靠度 |
|----------|------|--------|
| 下载量/收入 | Sensor Tower/data.ai | ⭐⭐⭐⭐ |
| DAU/MAU | 七麦/蝉大师（国内） | ⭐⭐⭐ |
| 用户评分 | App Store/Google Play/TapTap | ⭐⭐⭐⭐ |
| 社区舆情 | NGA/贴吧/Reddit/Discord | ⭐⭐⭐ |
| 版本节奏 | 官方公告/版本历史 | ⭐⭐⭐⭐⭐ |
| 职业赛场 | 赛事数据/选手采访 | ⭐⭐⭐⭐ |

### 竞品分析框架
```
一、市场表现（定量）
├── 下载趋势 / 收入趋势 / 排名变化
├── 分国家/分平台表现
└── 与同品类对比

二、产品特征（定性+定量）
├── 核心玩法对比矩阵
├── 商业化模式对比
├── 版本更新节奏对比
└── 社区反馈分析

三、洞察与启示（结论）
├── 竞品做对了什么
├── 竞品做错了什么
├── 对我们的启示
└── 建议的行动计划
```

### 竞品雷达图
选5-7个维度打分对比：
- 核心玩法深度 / 画面品质 / 社交系统 / 商业化体验 / 内容量 / 运营节奏 / 社区氛围

### 竞品监控自动化
- **定期追踪**：每周/每月自动拉取排名、评分、收入数据
- **版本追踪**：竞品每次更新都记录
- **舆情监控**：用LLM自动分析社区热点话题

## 案例
- **三角洲行动竞品分析**：对标COD/战地/逃离塔科夫的全维度对比
- **二次元赛道竞品矩阵**：原神/崩铁/鸣潮/绝区零四维对比

## 检查清单
- [ ] 数据来源是否可靠
- [ ] 是否有定量+定性双维度分析
- [ ] 分析结论是否可指导行动
- [ ] 是否建立了定期监控机制

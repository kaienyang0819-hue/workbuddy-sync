# 数据分析能力检查清单总纲

## 核心观点
数据分析是现代策划的核心竞争力。从"我觉得"到"数据表明"的转变，是策划从初级到高级的分水岭。本卡片汇总C10全部20张卡片的核心能力，形成终极自检清单。

## 总纲检查清单

### 一、基础指标理解
- [ ] 能清楚定义DAU/MAU/PCU等活跃指标
- [ ] 理解留存率各节点的意义（次留/7留/30留）
- [ ] 理解ARPU/ARPPU/LTV/CPI/ROI等商业指标
- [ ] 能解读漏斗转化率的含义

### 二、分析方法掌握
- [ ] 能设计并执行AB测试
- [ ] 能做漏斗分析定位流失节点
- [ ] 能做分群分析（RFM模型）
- [ ] 能做竞品数据对比分析
- [ ] 能做版本上线数据复盘

### 三、工具能力
- [ ] 能写基础SQL查询数据
- [ ] 能用Excel/Sheets做数据透视和图表
- [ ] 了解可视化工具（Tableau/Grafana）
- [ ] 能利用AI辅助数据分析

### 四、业务应用
- [ ] 能用数据支撑平衡性调整决策
- [ ] 能建立经济系统监控体系
- [ ] 能做数据驱动的新手体验优化
- [ ] 能根据数据异常快速定位问题

### 五、调研能力
- [ ] 能设计有效的用户问卷
- [ ] 能进行深度用户访谈
- [ ] 能结合定量定性做完整洞察

## 能力评估维度
| 级别 | 描述 |
|------|------|
| Lv.1 入门 | 能看懂基础数据报告 |
| Lv.3 应用 | 能独立做常规数据分析，用数据验证假设 |
| Lv.5 精通 | 能自助查数，建立监控体系，做深度归因 |
| Lv.7 专业 | 能设计AB测试体系，用AI提效，指导团队数据文化 |

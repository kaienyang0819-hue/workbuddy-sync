# TAPD项目管理实战指南

## 核心观点
TAPD是腾讯内部最主流的项目管理工具，也是策划日常打交道最多的系统之一。会用TAPD不等于会项目管理，但用好TAPD能极大提升团队协作效率。

## 方法论

### TAPD核心对象
| 对象 | 用途 | 策划常用场景 |
|------|------|-------------|
| 需求(Story) | 功能需求管理 | 提交新功能/系统设计 |
| 任务(Task) | 具体工作拆分 | 拆分需求为开发任务 |
| 缺陷(Bug) | BUG跟踪 | 报告和跟踪BUG修复 |
| 迭代(Iteration) | Sprint管理 | 版本迭代规划 |
| Wiki | 文档知识库 | 策划文档存放 |

### 需求管理最佳实践
1. **标题规范**：[模块]功能描述，如"[战斗]新增技能连携系统"
2. **描述模板**：背景→目标→详细设计→验收标准
3. **优先级标注**：P0紧急/P1高/P2中/P3低
4. **关联关系**：关联相关需求、Bug、测试用例
5. **状态流转**：草稿→评审中→开发中→测试中→已上线

### 迭代管理
- 每个Sprint建一个迭代
- 迭代开始时拖入本期需求和任务
- 每日更新任务状态
- 迭代结束时Review完成率和遗留项

### 数据看板
- **需求燃尽图**：跟踪迭代内需求完成进度
- **Bug趋势图**：新增vs关闭Bug趋势
- **工时统计**：各模块人力投入分析

### 与MCP集成
通过TAPD MCP工具可以：
- 自动查询/创建/更新需求和Bug
- 批量管理迭代和任务
- 自动化数据报告生成

## 检查清单
- [ ] 需求描述是否完整规范
- [ ] 优先级和状态是否及时更新
- [ ] 迭代看板是否每日维护
- [ ] 是否利用自动化工具提效

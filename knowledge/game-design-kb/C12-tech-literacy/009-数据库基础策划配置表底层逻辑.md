## 核心观点

策划的Excel配置表本质就是数据库表。理解数据库基础，能让配置表更规范不易出错。

### 核心概念映射
| 数据库概念 | 策划语言 | 举例 |
|-----------|----------|------|
| Table | 配置表Sheet | 英雄表、技能表 |
| Row | 一条数据 | 英雄ID=1001 |
| Column | 字段/属性 | 攻击力、血量 |
| Primary Key | ID列(唯一) | 英雄ID |
| Foreign Key | 引用其他表的ID | 技能表→英雄ID |

### 三大范式（策划版）
1. **一格一值**：不在一个格子里塞多个数据
2. **一表一主题**：英雄表不混技能详情，用ID关联
3. **不存可推导值**：最终攻击力=基础×系数，运行时算

### 配置表设计五步法
1. 确定主题（一表一主题）→ 2. 定义主键 → 3. 列举字段（原子化）→ 4. 标注引用 → 5. 添加校验

## 检查清单
- [ ] 每张表有唯一主键且不重复
- [ ] 跨表引用有校验机制
- [ ] 字段命名统一规范
- [ ] 一列只存一个值

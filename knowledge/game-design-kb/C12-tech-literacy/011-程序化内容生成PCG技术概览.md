## 核心观点

PCG（Procedural Content Generation）用算法生成游戏内容，是Roguelike、开放世界、无限关卡的技术基石。策划需理解PCG的能力与局限。

### PCG技术谱系
| 技术 | 生成内容 | 典型游戏 |
|------|---------|----------|
| 随机地牢生成 | 房间+走廊布局 | Hades, 以撒 |
| 噪声地形 | 高度图/生态分布 | Minecraft, 无人深空 |
| L-System | 植被/建筑 | SpeedTree |
| Wave Function Collapse | 瓦片地图 | 独立游戏 |
| BSP树 | 空间划分 | Roguelike经典 |
| AI辅助PCG | 关卡/叙事 | 前沿研究 |

### 策划与PCG的配合
1. **定义约束规则**：最小房间数、BOSS房必须出现、商店间隔
2. **设计种子池**：手工设计的模块让PCG组合
3. **质量过滤**：定义"好关卡"的判定标准（可达性、难度曲线）
4. **参数暴露**：将PCG参数做成策划可调的配置

### PCG的局限
- 生成内容缺乏"手工设计感"和叙事意图
- 极端情况可能生成不可通关的关卡
- 需要大量测试验证生成质量

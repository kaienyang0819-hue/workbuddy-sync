## 核心观点

声音是游戏体验的半壁江山。策划理解音频技术基础，才能与音频设计师高效协作，提出可实现的声音需求。

### 音频中间件
| 工具 | 特点 | 使用者 |
|------|------|--------|
| Wwise | 功能强大/3A标配 | 守望先锋/原神 |
| FMOD | 轻量灵活 | 独立/中型团队 |
| 引擎内置 | 简单直接 | 小项目 |

### 策划需知概念
- **3D音效**：声音有方向/距离衰减，增强空间感
- **RTPC参数**：实时参数控制（血量低→音乐紧张）
- **Sound Bank**：音频资源包，影响加载速度和内存
- **音频状态机**：根据游戏状态切换BGM（战斗/探索/菜单）
- **混音优先级**：多声音同时播放时的优先级排序

### 策划音频需求模板
```
场景：BOSS战二阶段
触发条件：BOSS血量<50%
音乐变化：探索BGM → 战斗BGM（2秒渐变过渡）
环境音：增加心跳声(3D)，随距离衰减
特效音：每次BOSS咆哮触发全屏低频震动
```

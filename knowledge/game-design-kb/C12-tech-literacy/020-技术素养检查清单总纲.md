## 核心观点

技术素养不是要策划会写代码，而是理解技术的能力边界和约束，能与程序/美术/QA高效沟通，提出合理可实现的设计方案。

## 六维能力检查

### 一、引擎与工具（基础）
- [ ] 了解项目使用的引擎及版本
- [ ] 能使用引擎编辑器进行基本操作
- [ ] 掌握版本控制工具（Git/SVN）
- [ ] 能独立使用配置表导出工具
- [ ] 了解热更新的能力和限制

### 二、图形与渲染（视觉）
- [ ] 理解DrawCall/面数/内存概念
- [ ] 知道渲染管线基本流程
- [ ] 能评估美术需求的性能影响
- [ ] 理解LOD/合批/遮挡剔除
- [ ] 了解不同平台的性能预算

### 三、网络与同步（多人）
- [ ] 理解帧同步/状态同步/客户端预测
- [ ] 知道延迟对设计的影响
- [ ] 了解断线重连的技术约束
- [ ] 理解服务端权威原则

### 四、物理与AI（运行时）
- [ ] 理解碰撞检测基本原理
- [ ] 了解NavMesh寻路系统
- [ ] 理解动画状态机
- [ ] 知道行为树/FSM的AI方案

### 五、数据与安全（后端）
- [ ] 配置表设计遵循数据库范式
- [ ] 理解客户端/服务端职责划分
- [ ] 知道常见作弊手段和防御原则
- [ ] 了解数据存储和同步方案

### 六、前沿技术（加分）
- [ ] 了解AI/ML在游戏中的应用
- [ ] 理解PCG程序化生成的能力
- [ ] 关注引擎新技术（Nanite/Lumen等）
- [ ] 能评估新技术对策划工作的影响

## 能力等级标准

| 等级 | 描述 | 典型表现 |
|------|------|----------|
| Lv.1 入门 | 知道技术名词 | 能听懂程序讨论 |
| Lv.3 应用 | 理解能力边界 | 提需求前考虑技术可行性 |
| Lv.5 熟练 | 能做技术评估 | 需求评审时指出技术风险 |
| Lv.7 专业 | 技术驱动设计 | 用技术特性创造新玩法 |

## 推荐学习路径
1. **第一步**：学会使用引擎编辑器（放物件/调参数/跑测试）
2. **第二步**：理解配置表→运行的完整管线
3. **第三步**：学习网络同步基础（多人游戏必备）
4. **第四步**：建立性能预算意识
5. **第五步**：关注AI/PCG等前沿技术

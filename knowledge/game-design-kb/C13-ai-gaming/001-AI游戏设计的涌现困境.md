## 核心观点

1. **AI小镇多数是"电子盆景"** — 玩家只能被动观察，缺乏深度互动，技术优化解决不了体验空洞问题
2. **规则优先于技术** — 先厘清"设计什么规则让涌现有价值"，再考虑"用什么AI技术实现"
3. **无冲突则无涌现** — 红绿灯诞生不是因为预设指令，而是因为"道路资源竞争"。稀缺和冲突是涌现的催化剂
4. **设计范式转型：上帝→园丁** — 不再编写结果（具体事件），而是设计土壤（规则环境），让AI自我生长出规则
5. **AI擅长广度，人类擅长深度** — AI能产生海量行为变化，但深度情感编排（《最后生还者》级叙事）仍需人类设计

## 关键方法论/框架

### 框架一：园丁式设计范式

| 维度 | 上帝脚本师（旧） | 园丁式创作（新） |
|------|----------------|----------------|
| 设计对象 | 具体事件/剧本 | 规则/环境/土壤 |
| 控制方式 | 预设所有结果 | 设定边界，放任涌现 |
| AI角色 | 执行者 | 自主决策者 |
| 玩家角色 | 体验预设内容 | 与AI共同创造 |
| 核心挑战 | 内容量 | 涌现质量与可控性 |

### 框架二：稀缺资源催化涌现法则

- **核心原理**: 稀缺制造冲突 → 冲突催化协作/竞争 → 协作/竞争产生涌现
- **三种稀缺类型**:
  - **限时**: 时间压力迫使快速决策
  - **限量**: 资源不足迫使分配与交易
  - **限路径**: 路线限制迫使策略选择
- **实验验证**: 食物减半 → 催生交易分工；"质疑驱动"规则 → 比追求和谐更易激发有价值互动

### 框架三：AI游戏设计的边界矩阵

| | AI擅长（广度） | 人类擅长（深度） |
|---|---|---|
| **应做** | 海量NPC行为变化、动态世界事件、个性化任务 | 核心叙事编排、关键情感节点、角色深度塑造 |
| **风险** | 完全涌现易失控、内容质量参差 | 内容量有限、难以个性化 |
| **结合** | AI生成变量 + 人类设定边界 = 有控制的涌现 |

## 设计检查清单

- [ ] **规则先行**: 是否先设计好规则环境，再考虑AI技术实现？
- [ ] **冲突存在**: 系统中是否存在稀缺资源制造的冲突？
- [ ] **涌现边界**: AI行为是否有明确的边界防止失控？
- [ ] **深度编排**: 核心叙事节点是否由人类手工编排？
- [ ] **玩家互动**: 玩家是否有对AI行为施加影响的手段？
- [ ] **观察≠互动**: 系统是否提供了超越"观察"的深度互动方式？

## 个人思考

1. **"规则优先于技术"是AI时代策划最重要的认知** — 很多团队先冲技术Demo，没有想清楚规则设计，结果做出来的就是"电子盆景"
2. **稀缺催化涌现可以直接指导设计** — 在AI NPC系统中故意制造资源稀缺，比给NPC写更多对话要有效得多
3. **与C1系统设计强关联** — 博弈论五要素中的"策略×信息×收益"本质上就是在制造稀缺和冲突
4. **园丁式设计是策划角色的重新定义** — 未来策划不是写脚本的人，而是设计生态系统规则的人

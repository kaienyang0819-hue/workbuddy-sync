## 知识卡片格式

每条知识以 Markdown 文件存储，包含：
- **标题与标签** — 便于检索
- **核心观点** — 3-5句精华概括
- **关键方法论** — 可复用的设计框架/工具
- **案例参考** — 实际游戏案例
- **设计检查清单** — 实操要点
- **来源信息** — 原文链接与时间

## 使用说明

1. 通过 `INDEX.md` 按标签/关键词快速查找
2. 每个目录下有 `_overview.md` 汇总该领域核心知识
3. 学习进度在 `LEARNING_PLAN.md` 中追踪

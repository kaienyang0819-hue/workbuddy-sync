- **两大关键坑（本次耗费大量时间才定位，务必记住）**：
  1. **代理坑**：环境有 `HTTP_PROXY/HTTPS_PROXY=http://127.0.0.1:54149`（WorkBuddy 沙箱透明代理），requests 会连 localhost MCP 都走代理导致 ConnectionReset/拒绝。**必须 `s.trust_env=False` + `s.proxies={"http":None,"https":None}` 直连 18060**。
  2. **xsec_token 坑**：`get_feed_detail` 之前报「笔记不可访问」以为是风控，其实是 xsec_token 被 `[:32]` 截断。**完整 xsec 是 base64 以 `=` 结尾的长串**，必须从 list_feeds 返回的 `f["xsecToken"]` 原样取、别截断。xsec 有时效性，抓完立即读详情。
  3. **进程生命周期坑**：MCP 用 Bash 工具 `run_in_background=true` 启动才持续存活；`( cmd & )` 子 shell 方式命令返回即被杀。taskkill 过 python 会让 MCP 半死，需重启。

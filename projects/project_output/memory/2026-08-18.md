## 三家 Agent 工具架构对比（补充）
- Codex 架构：客户端 → App Server（JSON-RPC/Thread 管理）→ Codex Core（Agent Loop）；无状态交互（每次重发全量历史），靠 prompt 缓存降成本，超限自动 compaction；沙箱 Seatbelt/Landlock；Rust
- DS Harness 架构：Cordis 插件树 8 层（框架/推理/工具/状态/控制/执行/组合/体验），配置即组合（Bundle/Profile/patch），append-only 事件日志全量可回放；TS/Node
- WorkBuddy 架构：五层（基础设施[本地+云端双模沙箱]/智能体引擎[NLU·规划·调度·监控]/能力服务[六大微服务]/业务应用[20+技能包]/用户交互[桌面·IM·小程序]），与 CodeBuddy 共享腾讯自研 Agent 底座
- 洞察：Codex=无状态调度 + 工程护栏；Harness=可组合运行时（可审计）；WorkBuddy=本地优先双模 + 业务场景封装。三层粒度差异明显：Harness 拆到框架层，WorkBuddy 封装到业务层

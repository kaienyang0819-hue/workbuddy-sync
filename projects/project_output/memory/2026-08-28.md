## 吃鸡节 AI 队友 / AIbot 脑暴
- **场景**：腾讯和平精英吃鸡节活动（KV、套装、空投、尖叫鸡道具、明星祝福、抖音直播、19.9 线下派对等已就位）
- **目标**：让 AI 队友（大厅/组队/局内）和 AIbot（局内敌人）承担"吃鸡节氛围代理"
- **核心判断**：符号已过饱和，缺的不是一个新鸡元素，而是一个会主动讲故事和玩梗的角色。AI 队友 = 主动开口主动演出；AIbot = 被迫演出
- **输出**：`吃鸡节_AI队友AIbot脑暴_20260828.html`
- **结构**：核心思路 → 6 个 AI 队友脑暴点 → 5 个 AIbot 脑暴点 → 3 个跨载体联动 → 总览表 → P0/P1/P2 优先级 → 5 个风险点
- **关键脑暴点**：
  - AI 队友「鸡语互学」「吉星报到」「局内鸡线报」「结算欢庆」（话术包级成本）
  - AIbot「尖叫鸡化武器」「鸡窝巡逻咯咯化 debuff」「空投守护者 boss」「被击倒咯咯哒嘲讽」「出生岛接机举牌」
  - 跨载体：AI 队友解说"鸡战" + 结算全员 cosplay + 鸡档案活动回顾
- **优先级**：P0 = 话术包 + 击倒动作 + 出生岛接机（活动前 1 周可上线）；P1 = 鸡冠挂件 + 尖叫鸡 AIbot + 鸡战解说；P2 = 鸡窝/空投 boss/结算动画/鸡档案
- **建议下一步**：P0 三点话术 + 一个挂件做小样，1 周内可评审原型

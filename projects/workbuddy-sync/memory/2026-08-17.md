# 2026-08-17

## 修复 workbuddy-sync 推送失败
- **症状**：sync.ps1 显示 "Pushed to GitHub" 但实际未推送（本地积压 7 个 commit，6/8~8/7）
- **根因 1**：脚本不检查 git push 退出码，失败仍打印成功
- **根因 2**：PowerShell host 安全策略禁止 git spawn 子进程（credential helper），导致 push 时拿不到凭据 → 401/静默失败；通过 Git for Windows 的 bash 执行 git 可绕过
- **修复**：sync.ps1 新增 Invoke-Git bash 包装（GIT_CONFIG_NOSYSTEM=1 + wincred + GIT_TERMINAL_PROMPT=0），所有 git 命令走 bash；检查退出码，失败退出
- **验证**：本地与远程同步到 937253c，sync 真实 push 成功

## 创建系统策划文档标准格式Skill

完成了策划文档生成模板的skill化工作:

### 1. 创建内容
- **Skill名称**: game-design-doc-template (系统策划文档标准格式)
- **安装位置**: `C:\Users\kaienyang\.workbuddy\skills\game-design-doc-template`

### 2. Skill结构
```
game-design-doc-template/
├── SKILL.md (skill说明文档)
├── README.md (使用说明)
├── requirements.txt (依赖: openpyxl>=3.1.0)
├── scripts/
│   └── generate_design_doc.py (核心生成脚本)
└── examples/
    └── create_sample_doc.py (示例代码)
```

### 3. 核心功能
- 提供标准化的Excel策划文档生成API
- 统一的样式规范(蓝色系、微软雅黑字体)
- 4个标准页签结构
- 便捷的函数接口(add_title_1, add_rule_title, add_label等)

### 4. 样式规范要点
- 颜色体系:深蓝#5B9BD5、中蓝#9BC2E6、浅蓝#BDD7EE
- 字体:微软雅黑,正文字号12pt
- 标题和正文都不换行
- 规则内容必须有序号(1、规则说明 2、交互图 3、表格配置)
- 待决策项缩进3个单元格

### 5. 使用方法
在WorkBuddy中调用:
```python
use_skill("game-design-doc-template")
```

然后使用提供的API函数生成标准化策划文档。

## 优化系统策划文档Skill

根据用户反馈,对skill进行了两项优化:

### 1. tlog页签事件名不换行
- 修改 `align_center` 对齐方式,从 `wrap_text=True` 改为 `wrap_text=False`
- tlog表格的事件名和内容单元格不再换行,保持整洁

### 2. 规则说明内容添加前置序号
- 为 `add_content()` 函数新增 `auto_number=True` 参数
- 规则说明内容自动添加"1. "前缀
- 例如: "玩家可通过小地图..." → "1. 玩家可通过小地图..."

### 3. 更新的文件
- `scripts/generate_design_doc.py` - 核心脚本
- `SKILL.md` - skill说明文档
- `README.md` - 使用说明
- `QUICK_START.md` - 快速开始指南
- `examples/create_sample_doc.py` - 示例代码
- `MEMORY.md` - 长期记忆

### 4. 示例用法
```python
# 规则说明自动添加序号
row = add_content(ws, row, '玩家满足条件后可触发功能', col=5, auto_number=True)
# 输出: "1. 玩家满足条件后可触发功能"
```

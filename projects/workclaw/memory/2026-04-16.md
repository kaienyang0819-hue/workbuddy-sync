# 2026-04-16 工作日志

## AI NPC 对话认知模型设计

- **背景**: 为AI NPC语音交互设计打断控制机制，场景为FPS/战术游戏中的AI队友
- **设计演进路径**:
  1. v1 消息优先级分层（AI输出打标签，区分可打断/不可打断）
  2. 用户修正：被打断的内容不需补充，只保上下文
  3. 用户修正：不应该判断AI说什么来决定打断，应该判断**玩家说什么**来决定打断
  4. 用户修正：战术指令不应无条件打断+服从，AI有策略能力会argue
  5. 连环打断场景：渐进退让模型（完整argue→压缩警告→服从+自保）
  6. 2+2场景：意图路由模型（判断谁在对谁说话）+ 各AI独立认知循环
  7. 从"打断规则"升级为"对话认知模型"——持续感知认知循环
  8. **最终方案 — 话轮管理系统**（只管嘴巴，不管脑子）：
     - **三维输入**：玩家语音(外部被动) + AI自身决策(内部主动) + 战场事件(环境推送)
     - **5种说话行为**：CONTINUE(继续说) / STOP(停止说话) / INTERJECT(插话) / SWITCH(新话题说话) / SILENCE(保持静默)
     - SWITCH vs INTERJECT：SWITCH=自我打断切换话题，INTERJECT=打断别人开口
     - **核心模块**：对话意图模型（综合三维输入+AI当前状态，持续评估，输出5种行为）
     - 策略模型/人设/LLM标记为下游系统，通过importance标签+策略翻转信号与话轮系统交互
     - 2+2模式：仅新增对话路由层(WHO→TO WHOM)，话轮逻辑完全复用1+1
- **产出文件**:
  - `G:\project_output\ai_npc_conversation_cognition_framework.html` — 最终版认知模型框架（v1已删除）
- **核心设计原则**:
  - 被打断的内容不补充，只保上下文供策略模型消费
  - 判断对象是玩家输入（不是AI输出）
  - AI有主见会argue，但渐进退让（最多2次后服从）
  - 2+2场景用意图路由+主人绑定简化
  - 认知驱动 > 规则驱动

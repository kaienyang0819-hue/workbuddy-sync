### 任务背景
组委会对原 PPT（20页，蓝色科技风，主色 #0043DA/#00B3FF）提出 4 条补充诉求：
1. 深挖 LLM × 游戏范式（记忆/系统隔阂/叙事结合/涌现性）
2. 当前技术与体验设计的限制 + 内部思辨实验

### 关键决策（用户确认）
- **不改动原 PPT 结构**，补充内容作为独立模块追加在末尾（不起章节名）
- **7 页补充** + 1 页导览 = 8 页，中文为主，视觉沿用原 PPT 蓝色系
- **陪玩 vs 独立人格**：和平从陪玩转向独立人格，核心原因是陪玩无法支撑长期关系与养成。王牌案例——玩家辱骂 AI 时独立人格会生气拒绝指令
- **策略大模型**可公开讲架构（记忆 + 画像 → 风格适配）
- **行业视角**重心为选型对比（自研 vs API / 云 vs 端 / 纯 LLM vs 混合）
- **B1 改名为"制作过程难点"**（不是限制）：训练数据 / GPU / 通用 vs 垂直 / 评测
- **低活玩家数据**显著提升（用户会补具体数字）


## full-cycle-workflow 闭环 skill 建立与打包

- 从 KM 文章《我不想再给 AI 当测试了》引入 full-cycle-developer 方法论（@tencent/fcd-ai）
- 安装 fcd v0.4.0，拆解其 skill 结构，改造为通用闭环 skill：full-cycle-workflow（用户级 ~/.workbuddy/skills/full-cycle-workflow/，含 SKILL.md + quality-gates.md + experience.md + README.md）
- 五段闭环：需求评审 → Plan 实现清单 → 逐点产出 → 自验收（文档门禁 + 像素比稿）→ 经验沉淀
- 打包分享：full-cycle-workflow.skill（5.3KB）+ full-cycle-workflow-portable.zip（456KB，含便携 fcd CLI 及依赖）
- 依赖说明：像素比稿复用 fcd diff（pixelmatch + SSIM），便携包已含依赖，同事需 Node ≥18.3.0

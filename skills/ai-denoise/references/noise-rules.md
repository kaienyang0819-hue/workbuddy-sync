# 噪声规则库

每条规则附样例与出处（用户历史反馈）。新增规则追加到文末"进化日志"。

## A. 直接删除

| 编号 | 噪声 | 识别特征 | 样例 | 出处 |
|---|---|---|---|---|
| A1 | 套话、汇报体 | 连接性空话，删后语义不变 | 总之、值得注意的是、不难发现、众所周知、由此可见、开门见山、汇报概要、综上所述 | 2026-06-05 汇报 PPT 15→7 页去汇报腔 |
| A2 | 空泛价值句 | 只有价值词，没落到具体功能/收益 | "提升体验""增强沉浸感""更有价值""打造闭环""全方位赋能" | 用户降噪规则 |
| A3 | 演绎/氛围描写 | AI 自加的比喻、拟人、情绪铺垫 | "就像一位默默守护的伙伴""让每一局都充满温度" | 用户降噪规则；禁止脑补 |
| A4 | 重复总结 | 正文已说清，结尾/段尾再复述 | 段尾"综上所述，…"；与上一条重复的"使回答更贴近"尾句 | 2026-10-27 全页去重 |
| A5 | 无信息量修饰 | 副词堆砌、口号式收尾 | 非常、极其、十分、切实、真正；"让我们一起…！" | 用户降噪规则 |
| A6 | 对话残留 | 对话中为澄清/论证产生的括号注释、口语前缀 | "（各自减各自，无标杆）""（非总人数）""（调度分）"；"关键：""体验更顺" | 用户级长期记忆·文档写作规范 |
| A7 | 过程性说明 | 讲"我怎么做出这份内容"的方法论、提问原则、口径详解、"目的/对应观察"注释列 | 问卷里的提问原则、题面口径详解、"对应观察"列 | 2026-10-13 问卷定稿"只留下游可用的内容" |
| A8 | 独立元信息块 | 用户未要求的独立说明模块 | "实施顺序与验收口径""来源与解释边界"整块 | 2026-10-27 v2 整块删除 |
| A9 | 场景外内容 | 超出本次文档目标的建议、复盘、方案 | 评测意见里的复盘/后续建议；归因报告里的解决方案；分享稿里的工程做法 | 游戏评测；2026-05-30 流失报告 |
| A10 | 发散内容 | 偏离主线的扩展；示例超过必要数量 | 叙事 NPC 页示例只留 2 个核心案例 | 2026-05-30 |
| A11 | 无依据内容 | 资料中找不到出处的推断、孤立注释 | "定制模型未被定价" | 2026-06-15；禁止脑补 |
| A12 | 数据解读性形容 | 数据后附主观判断 | "高达 36.3%""显著提升""仅有" | 数据只陈述客观值 |

注意：A12 中"仅""只"若承担口径区分（如"仅体验 1 场"是分组名）则保留。

## B. 虚话换实话

| 原表述 | 处理 |
|---|---|
| "有什么用/意义" | 原文有收益信息 → 改写为具体收益（数值、功能、效果）；没有 → 删除或标【待补：具体收益】 |
| "优化了体验" | 原文有改动信息 → 写具体改了什么、玩家/读者得到什么；没有 → 同上 |
| 讲机制的设计意义 | 公告/玩家文案场景 → 改为"怎么用 + 得到什么"；分享/方案场景 → 有论证的价值判断保留，空口号删 |

铁律：B 类只能用原文已有的信息重组，任何新数字、新效果都不得出现。

## H. HTML 专项

| 编号 | 规则 |
|---|---|
| H1 | 删装饰元素：无信息的 eyebrow 小标题、标语、徽章、emoji、纯装饰页脚 |
| H2 | 删占位注释、"本页导航"类说明文字、对页面本身的元描述（"本页将…"） |
| H3 | 删内容后收紧布局：网格列数随卡片数调整，不留空洞；保持紧凑 |
| H4 | 删除模块对应的 CSS 可顺带清理；其他冗余 CSS 仅可选，不得破坏样式 |
| H5 | 折叠收起默认不加；用户要求时用 `<details>` 实现 |
| H6 | 不动数据可视化的数据与口径注释 |

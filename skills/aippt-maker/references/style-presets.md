# 风格预设库

> 选择一个编号即可应用完整的视觉风格。也可以在预设基础上微调，或完全自定义 theme。

---

## 预设 1：商务专业（Business Professional）

```
1. 整体风格：商务专业，沉稳大气，现代感强，适合汇报、提案、商业分析场景。
2. 背景：深蓝灰 #1B2838，纯色或极浅纹理，深色系。
3. 字体：标题使用微软雅黑（Microsoft YaHei），正文使用思源黑体（Noto Sans SC）。英文标题 Montserrat，英文正文 Inter。
4. 配色：主色调深蓝灰 #1B2838，辅色调浅灰白 #E8ECF1（文字色），强调色商务蓝 #3B82F6。
5. 视觉元素：简洁线条分隔，圆角卡片容器，留白充足，数据用大字突出，图标用线性风格。
```

## 自定义风格

如果以上预设都不合适，可以完全自定义。请按以下 5 个维度描述：

1. **整体风格**：一句话概括视觉调性
2. **背景**：背景色（含 hex 值），深色系还是浅色系
3. **字体**：标题字体、正文字体（中英文分别指定）
4. **配色**：主色调、辅色调、强调色（均含 hex 值）
5. **视觉元素**：装饰语言、图形风格、排版特征

# 质量门禁（自验收对照基准）

按产出类型选用，逐条对照，四选一标注（`✅` / `❌` / `⛔` / `[~]`）。

## 一、文档质量门禁（策划案 / 文档 / 问卷 / PPT / Excel）

### 去对话化
- 删掉对话过程中产生的澄清性、论证性备注（括号里的解释、口语前缀如「关键：」「体验更顺」等）。
- 只保留规则定义本身，文档干净可直接对外。

### 口径一致
- 全文术语、定义、口径统一，前后不矛盾。
- 参照系正确，对齐目标用户群体，不照搬其他产品逻辑。

### 数值对齐
- 数值前后一致，计算公式正确，单位统一。
- 表格 / 正文 / 图表数据口径一致。

### 信源核验
- 关键判断标注信息来源与可信度。
- 不脑补、不依赖搜索摘要，核验原文。

### 图文一致
- 图与文匹配，图表标注与正文一致。
- 布局优化不丢关键信息。

### 图表规范
- 图表用柱状图，禁饼图。
- 金融类：涨红跌绿。

### 结构规范
- 先结论后方案。
- 表格 > 列表 > 段落。
- 中文表达，避免英文句子。

## 二、像素级比稿（HTML 页面 / UI 原型 / 界面还原）

当产出是「照着参考图 / 设计稿做界面」时：

1. 产出界面截图，与参考图裁齐同一区域。
2. 量化比对（复用已安装的 fcd 命令）：
   ```bash
   fcd crop <图> x1,y1,x2,y2   # 裁剪对齐，闭区间
   fcd diff <参考图> <实现图>    # pixelmatch + SSIM，输出 weighted 分与 diff 高亮图
   ```
3. `weighted ≥ 98` 且高亮图无肉眼可见红区 → 视觉基线通过；低分先看高亮图定位，再逐项查：尺寸 / 间距 / 圆角 / 描边阴影 / 字号字重行高 / 颜色 / 图标 / 文案 / 层级遮挡。

## 三、图片产出（生图 / 改图）

- 要素齐全：需求里要求的元素都出现。
- 风格一致：多图之间、与参考风格一致。
- 文字正确：图中文字无错别字、无乱码。
